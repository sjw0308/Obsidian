Overview
- 이 수업에서는 NP-hard 문제들을 다룰 것이다. 
	- NP-hard: 풀이가 Polynomial time에 풀리지 않는 문제 (주어진 답에 대한 검증도 P일 필요가 없음)
- NP-Completeness를 다루는 방법은 총 3가지가 있음
	- Sacrifice generality
		- 일반성을 포기하는 방법. 모든 경우에 적용할 수 있는 해가 아닌 특정 경우에 적용할 수 있는 Polytime solution을 찾는 방법
		- e.g. Independent Set 은 일반적으로 NP-Complete지만 Independent Set in Tree 는 Polytime에 풀 수 있다. 
	- Sacrifice optimality
		- 최적성을 포기하는 방법. 완벽한 해가 아닌 정답과 최대 얼마나 차이가 나는지를 증명할 수 있는 solution을 찾는 방법
		- find solution of cost in range $\left[ \left( \frac{1}{c} \right) \cdot OPT,\ c \cdot OPT \right]$, 이 때 c는 Approximate factor라고 하고, OPT는 Optimal cost 라고 한다. 
		- e.g. Set Cover은 $O(\log n)$ 인 approximate factor를 이용해서 approximate할 수 있다. 
	- Sacrifice efficiency
		- Polytime이 아니더라도 부르트포스 보다 빠른 방법을 찾거나 새로운 parameter를 도입해서 비교적 빠른 풀이를 찾는 방법. 
		- e.g. Traveling Salesman 문제는 $2^{O(n)}$ 으로 풀 수 있는데 이는 Polytime이 아니지만 brute-force로 풀었을 때인 $n!$보다는 빠르다
		- e.g. Vertex Cover 문제는 vertex cover set의 size가 최대 k일 때로 가정하여 $2^{O(k)}n^{O(1)}$로 풀 수 있고, 이는 원래 풀이인 $2^{o(n)}$보다 빠를 수 있다.  

Planar Graphs
- Def. 평면에서 모든 edges가 endpoint에서만 intersect를 만드는 graph이다. (평면에서 모든 edges가 서로 교차되지 않는 graph)
- Euler's Formula
	- G가 connected plane graph라면 $v-e+f = 2$ 이다. (v,e,f는 각각 vertices, edges, faces의 개수이다. Face는 edge로 나뉜 공간)
	- Pf>
		- case 1: G가 Tree일 때: cycle이 없어서 f=1, tree의 특성으로 v = e+1. $\square$
		- case 2
			1. G에서 어떤 Complete cycle을 생각하자
			2. 그 Complete cycle에서 edge를 하나 제거하자
			3. 그러면 Cycle은 없어졌지만 $v-e+f$값이 유지된다. (e가 1감소, f가 1감소)
			4. 이를 반복하면 결국 G와 같은 $v-e+f$값을 갖는 tree를 만들 수 있으므로 $\square$
	- Corollary
		- 어떤 planar graph G의 모든 planar embedding은 같은 수의 faces를 갖는다.
	- Corollary
		- For a connected, simple planar graph G with at least three vertices, we have $e\leq 3v-6$
		- simple: loop(edge하나로 자기 자신으로 돌아오는 edge)가 없고, 두 vertices사이를 잇는 edge가 최대 하나인 graph를 의미한다. 
		- Pf>
			- The sum of all face-boundary lengths is 2e.
			- Thus we have $3f \leq 2e$
			- 여기에 오일러 방정식을 적용하면 됨 $\square$
	- Corollary
		- $K_5$ 는 plannar가 아니다. (vertices가 5개인 완전연결 그래프)
	- Corollary
		- For a connected, simple planar graph G with at least $g$ vertices, where $g\geq 3$. If G has no cycle of length < g, $e\leq \frac{g}{{g-2}}(v-2)$
		- 이전 Corollary에서 3을 g로 바꾼 걸로 증명 가능
	- Corollary
		- $K_{3,3}$은 planar가 아니다. (vertices 3개인 set이 다른 set의 vertices와 모두 edge로 연결된 graph)
- Forbidden Graph 
	- A subdivision of a graph G
		- G에서 edge에 vertex를 껴 넣은 그래프를 G의 subdivision이라고 한다. 
	- Lemma. Planar graph는 $K_{5}$나 $K_{3,3}$의 subdivision을 subgraph로 갖지 않는다.
		- pf>
			- Planar graph의 subgraph 또한 plannar이다. 
			- G의 subdivision이 planar라면, G또한 planar이다. 
	- Theorem(Kuratowski). 그래프가 plannar이다. $\Leftrightarrow$ 그래프가 $K_{5}$나 $K_{3,3}$의 subdivision을 subgraph로 갖지 않는다.
- Forbidden minor
	- A minor of a graph G
		- G에서...
			1. subgraph이거나
			2. edge를 없애고, 연결하던 두 vertices를 하나로 merge
		- 위 두 작업을 반복해서 얻을 수 있는 그래프를 의미한다. 
	- Lemma. Planar graph는 $K_{5}$나 $K_{3,3}$의 subdivision을 minor로 갖지 않는다.
		- pf>
			- Planar graph의 subgraph 또한 plannar이다. 
			- G의 subdivision이 planar라면, G또한 planar이다. 
	- Theorem(Wagner). 그래프가 plannar이다. $\Leftrightarrow$ 그래프가 $K_{5}$나 $K_{3,3}$의 subdivision을 minor로 갖지 않는다.
- Fary's Theorem
	- 모든 simple planar graph는 모든 edge가 선분인 그래프로 planar embedding할 수 있다. (edge crossing 없이)
	- Pf> Using induction
		- Base Condition: vertex개수 3개 -> 자명
		- Induction Hypothesis: vertex개수가 n-1개인 maximal planar graph G가 선분으로 embedding할 수 있다고 하자.
			- maximal planar graph는 planar인데 하나의 edge만 추가해도 planar가 아니게 되는 graph를 의미한다. 
		- Induction Step
			- G가 n-vertex maximal planar graph라고 한다면, G의 모든 face는 triangle이다. (outer face 포함)
			- 따라서 $3f=2e$ 오일러 공식에 의해서 $e=3n-6$
			- $3n-6 = \sum_{v\in V}d(v)/2$ ($d(v)$는 degree로 연결된 edge수)
			- 이때 $d(v) \geq 3$ 이므로 degree가 5이하인 vertex가 적어도 4개 존재한다. (비둘기 집으로 쉽게 증명 가능)
			- 그런데 outer face가 triangle이므로 적어도 하나는 내부에 존재한다. 
			- 그 내부에 존재하는 vertex와 연결된 edge까지 없애면 IH에 만족하는 graph가 남는다. 
			- IH를 쓰고 마지막에 없앤 vertex와 edge를 추가하면 끝
			- (아마도 degree가 5이하 + 내부면 몇몇 캐이스로 특정이 가능해서 증명이 가능하기 때문인듯)

Coloring Problem
- Coloring Problem (Optimization)
	- Given a graph G=(V,E), find a smallest value k s.t. G is k-colorable.
- k-Coloring Problem (Search Version)
	- Given a graph G=(V,E), and an integer k, check if G is k-colorable, and find a k-coloring
- Known Results
	- The 2-coloring problem can be solved in polynomial time for any graph
	- The 3-coloring problem is NP-complete for planar graphs
		- More generally, the 3-coloring problem cannot be solved in $2^{O(\sqrt n)}$ time for planar graphs under some reasonable assumption.
	- The the 3-coloring problem cannot be solved in $2^{O(\sqrt n)}$ time for planar graphs
	- The 4-coloring problem can be solved in polynomial time for planar graph
		- Indeed, every planar graph can be colored with four colors.
- Theorem. Every planar graph has 6-coloring
	- Pf> Using induction
	- Base Condition: $n\leq 6$ 이면 자명
	- Induction Step:
		- Fary's Theorem에서 degree가 5이하인 임의의 vertex를 v라고 하면 $G'=G-v$ 가 6-coloring이 가능함
		- 이후 v를 이웃들과 다른 색으로 칠한 것으로 추가하면 됨 $\square$
- Theorem. Every planar graph has a 5-coloring
	- Pf> "
	- Maximal plane graph G에 대해서 증명하자
	- 각 vertex에 대하여 $C(v)$ 를 v에 칠할 수 있는 color의 set으로 정의하고 시작은 $C(v) = \{1,\dots 5\}$ 로 모두 해놓고 모든 vertex를 하나하나 칠한다고 생각하자
	- Given a near-maximal plane graph G'에 대하여(near-maximal은 outer face를 제외한 모든 face가 triangle이고 outer boundary가 cycle인 planar graph이다. B는 boundary vertices)
		- two adjacent vertices x, y in B를 $\alpha, \beta$로 칠한다
		- $|C(v)|\geq3$ for all other vertices in B
		- $|C(v)|=5$ for all vertices not in B
	- Case1.
		- B를 가로지르는 현이 있는 경우. 이를 uv라고 하자
		- uv로 나뉜 두 그래프 중 xy를 포함한 부분에 Induction Hypothesis를 적용 후 나머지 부분에 uv를 기준으로 IH를 적용하면 됨 $\square$
	- Case2. 
		- x와 연결된 vertex중 y가 아닌 걸 $v_{0}$ 라고 하고 그 것과 이웃인 모든 vertices를 x부터 $x, v_{1}, v_{2}, \dots, v_{t}, w$ 라고 하자(w, x, $v_{0}$만 B에 속한 vertices)
		- $v_{0}$ 도 B에 속했으므로 $|C(v_{0})|\geq 3$이다. 이때 $\alpha$가 아닌 두 색 $\gamma, \eta$ 를 고르자
		- 위 두 색을 $v_{0}$의 이웃인 모든 vertices 중 x, w가 아닌 것들의 C(v)에서 제거한다. 
		- $G'' = G'- \{v_{0}\}$이 그럼 IH에 해당 되므로 IH를 적용하고, $v_{0}$를 $\gamma, \eta$ 중 w에 칠하지 않은 것으로 칠하면 G'도 색칠할 수 있다. 
- Lemma. A planar graph has balanced separator of size $O(\sqrt n)$
	- Def. G = (V,E)의 Balanced separator를 S라고 하면 G\[V-S]의 모든 component의 크기가 $\frac{2n}{3}$이하로 만드는 Set을 의미한다. 
- Lemma. 3-coloring can be solved in $2^{O(\sqrt n)}$ time for planar graphs.
	- 색칠 문제를 위 Lemma를 이용해서 S로 나누고, S로 나뉜 companent들을 생각하면 아래와 같이 생각할 수 있다. 
	- $T(n) \leq 2^{O(\sqrt n)}(T(n_{1})+\dots+T(n_{k})),\ where n_{1}+\dots+n_{k} \leq n\ \& each\ n_{i}\leq \frac{2n}{3}$  
	- 위 과정을 recursive하게 반복하면 증명 끝 $\square$
