
- 대리자(Delegate)
	- 만들 때: ```한정자 delegate 반환형식 대리자_이름(매개변수_목록);```
	- 쓸 때: ```대리자_인스턴스_이름 = new 대리자_이름(메소드_이름);```
	- 대리자는 미리 인스턴스를 만들어 두고 나중에 메소드를 쓸 때 사용한다. 이때 메소드는 대리자와 반환형식과 매개변수_목록이 같아야 한다. 
	- 대리자는 코드 자체를 넘기고 싶을 때 사용한다. 대리자는 메소드에 대한 참조이므로 여러 메소드 중에서 하나를 정해야할 때 미리 만들어두고 대리자로 받아서 보내면 된다. 
	- 일반화 대리자
		- ```한정자 delegate 반환형식 대리자_이름<T> (<T>를 이용한 매개변수 목록);```
	- 대리자 인스턴스 하나에 여러 개의 메소드를 연결할 수 있음(+ 연산자를 이용해서)
	- 익명 메소드
		- 대리자 인스턴스에 메소드를 전달할 때 이름 없는 익명 메소드를 만들어서 전달할 수 있음
		- ```C#
		  instance_name = delegate (int a, int b){
		      return a+b;
		  }
		  ```

- Event
	- 사용 방법
		1. 대리자를 선언. 이때 대리자는 클래스 안 또는 밖에 선언 가능합니다.
		2. 클래스 내에 1. 에서 선언한 대리자의 인스턴스를 event 한정자로 수식해서 선언
			- ex) ```public event 대리자_이름 이벤트 이름```
		3. 이벤트 핸들러를 작성. 이벤트 핸들러는 1. 에서 선언한 대리자와 일치하는 메소드면 됩니다. 
			- 핸들러는 진짜 그냥 대리자 형식에 맞는 메소드 하나임
		4. 클래스의 인스턴스를 생성하고 이 객체의 이벤트에서 3. 에서 작성한 이벤트 핸들러를 등록합니다. 
			- ```인스턴스.이벤트_이름 += new 대리자_이름(3.에서 짠 핸들러 이름)```
		5. 이벤트가 발생하면 이벤트 핸들러가 호출됩니다. 
	- 이거 왜씀?
		- 이벤트와 대리자의 가장 큰 차이점은 이벤트는 public이어도 외부에서 직접 사용할 수 없다는데 있다!
		- 이벤트는 클래스 내부에 구현되어 있는 부분에서만 발생시킬 수 있다는 차이점이 있음
