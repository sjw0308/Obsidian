# 운영체제 모의시험 05 정답·해설

- 제한시간: 80분 / 100점 / 8문항
- 시험지는 영어로 작성했으며, 정답·해설은 한국어입니다.
- 제외 유형: OS 세 핵심 역할 설명, fork·exec 비교, bounded buffer의 producer/consumer 코드 순서 작성, MLFQ의 I/O 양보 악용 방지.
- 개념·응용·계산 혼합형입니다.
- 구간은 [시작,끝), turnaround=완료-도착, response=최초 실행-도착입니다. 근거가 맞으면 동등한 표현과 정확한 분수·소수 답을 인정합니다.

## 1. Controlled kernel entry (12점)

(가) 타이머 인터럽트 발생→커널 핸들러 진입→스케줄링 판단. 각 단계 및 비자발적 제어권 회수에 총 4점.

(나) 짧은 시스템 호출을 처리한 뒤 같은 프로세스로 복귀한다. 커널 진입은 있으나 프로세스 전환은 필수가 아니다. 예 2점, 구분 2점.

(다) vector는 사건 종류의 진입 핸들러, syscall 번호는 요청 서비스 함수를 고른다. 각 2점.

## 2. A race despite coherent caches (12점)

(가) T1 load10→T2 load10→각자 add11→각자 store11. 최종11. 순서 4점, 결과1점.

(나) 전체 read-modify-write를 같은 락으로 보호하거나 원자적 증가 명령을 쓴다. 3점.

(다) coherence는 cache 사본의 일관성을 다루지만 여러 명령 전체를 하나의 원자적 연산으로 만들지 않는다. 4점.

## 3. STCF with staggered arrivals (14점)

A[0,2) → B[2,3) → C[3,4) → B[4,6) → D[6,8) → A[8,13)

작업 순서 A,B,C,D: 완료=[13, 6, 4, 8], turnaround=[13, 4, 1, 2], 평균=5; response=[0, 0, 0, 0], 평균=0.

실행 구간6점, 완료·turnaround 각2점, 평균 각2점.

## 4. Sleeping lock handoff (12점)

(가) 대기자 큐 등록/guard 해제→소유자 unlock에서 unpark→대기자 park로 영구 대기. 4점.

(나) 큐 등록 후 guard 해제 전 setpark. 이후의 빠른 unpark를 기억해 다음 park가 잠들지 않게 한다. 위치2점, 의미2점.

(다) 락 소유권을 깨운 대기자에게 넘겨 새 진입자의 가로채기를 막는다(2점). guard 자체가 선점·인터럽트를 금지하지 않는다(2점).

## 5. Semaphore signals and readers (12점)

(가) 안전하다. 세 post가 허가3개를 남겨 세 wait가 소비한다. 완료 후 기록 가시성을 제공하는 정상 세마포어를 가정한다. 판단2점, 설명2점.

(나) count 증감과 첫·마지막 판정 및 관련 획득·해제 프로토콜을 함께 보호한다. 4점.

(다) 기존 reader가 끝나기 전에 새 reader가 계속 들어와 count가0이 되지 않으면 writer가 대기한다. 4점.

## 6. Deadlock, livelock, and ordering (12점)

(가) 단독 소유/보유하며 추가대기/강제회수불가/세 스레드의 원형대기. 각1점.

(나) L1<L2<L3 순으로 모두 획득, circular wait 제거. 규칙2점, 조건2점.

(다) livelock2점, 무작위 backoff 등 재시도 분산2점.

## 7. Parallel performance budget (12점)

T(N)=60+180/N+2(N-1). (가) T4=111초, speedup=80/37≈2.162; T8=96.5초, speedup=480/193≈2.487. 각 경우 시간2점·speedup1점.

(나) overhead 무시 상한1/0.25=4배. 3점.

(다) 8코어가14.5초 빠르다. 선택1점, 차이2점.

## 8. Queues, migration, and locality (14점)

(가) 미이동: CPU0 A[0,10),B[10,14); CPU1 C[0,3),D[3,5),idle[5,14), makespan14. 이동: CPU0 A[0,10); CPU1 C[0,3),D[3,5),migration[5,6),B[6,10), makespan10. 정책별 구간3점·makespan1점.

(나) cache 재가열/affinity 손실2점, 공유 큐의 락 경합·직렬화2점.

(다) 아니다. owner와 stealer의 동시 접근을 보호하는 락 또는 올바른 동시성 큐 설계가 필요하다. 2점.
