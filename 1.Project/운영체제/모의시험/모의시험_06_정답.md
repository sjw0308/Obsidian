# 운영체제 모의시험 06 정답·해설

- 제한시간: 180분 / 100점 / 20문항
- 시험지는 영어로 작성했으며, 정답·해설은 한국어입니다.
- 제외 유형: OS 세 핵심 역할 설명, fork·exec 비교, bounded buffer의 producer/consumer 코드 순서 작성, MLFQ의 I/O 양보 악용 방지.
- 계산 전용입니다. FIFO, SJF, STCF, RR, MLFQ, lottery, stride, CFS, Amdahl, 다중 CPU 스케줄링 각 2문항이며 각 문항은 5점입니다.
- 구간은 [시작,끝), turnaround=완료-도착, response=최초 실행-도착입니다. 근거가 맞으면 동등한 표현과 정확한 분수·소수 답을 인정합니다.

배점: 실행 구간 3점; turnaround 벡터·평균 1점, response 벡터·평균 1점.

## 17. Amdahl 1 - serial fraction and overhead (5점)

S=0.2: 0.4=S+(1-S)/4. 실제 T8=40+160/8+3.5=63.5초, T16=40+10+7.5=57.5초. 각1점.

실제 speedup8=400/127≈3.150, speedup16=80/23≈3.478. 각0.75점, 16코어 선택0.5점.

## 18. Amdahl 2 - two scaling regions (5점)

개선 전 T8=30+180/8+90/4=75초, speedup4(1.5점). 개선 후 T8=15+22.5+22.5=60초, speedup5(1.5점).

무한 코어: 개선 전300/(30+22.5)=40/7≈5.714; 개선 후300/(15+22.5)=8. 각1점. 4코어 제한 영역이 무한 코어에서도 남는다.

## 19. Multiprocessor 1 - stealing with a cost (5점)

X: CPU0 A[0,9),B[9,14),C[14,17); CPU1 D[0,4),E[4,6),idle[6,17).

Y: CPU0 A[0,9),B[9,14); CPU1 D[0,4),E[4,6),migration[6,8),C[8,11),idle[11,14). 정책별1.5점.

유용CPU 합23. X makespan17, 이용률23/34≈67.65%; Y makespan14, 이용률23/28≈82.14%. 정책별1점. migration은 유용실행에 포함하지 않는다.
