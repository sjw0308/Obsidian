rm, p_theta - T, P_avg-T, rms(p_theta-T), t없이 P의 표준편차

앞선 두 연구를 통해 우리는 Reward Hacking을 완화하기 위해서는 Reward Model의 불확실성을 보다 정확하게 추정하는 것이 중요하다는 점에 주목하였다. 이에 여러 예측을 결합하는 Ensemble 방법을 활용하여 uncertainty를 추정한다면, 단일 모델을 기반으로 한 uncertainty보다 더 신뢰도 높은 불확실성 정보를 얻을 수 있지 않을까라는 질문을 제기하였다. 나아가 이렇게 추정한 uncertainty를 기반으로 보다 적절한 penalty를 부여한다면, 기존 방법보다 Reward Hacking을 더욱 효과적으로 완화할 수 있을 것이라 기대하였다. 


기본적인 실험 구조는 **From Curiosity to Caution: Mitigating Reward Hacking for Best-of-N with Pessimism**의 설정을 따른다. 기존 Caution 방법에서는 하나의 Predictor가 예측한 hidden state와 Reward Model(RM)의 실제 hidden state 사이의 오차를 uncertainty로 사용한다. 본 연구에서는 이를 확장하여 여러 개의 Predictor를 학습하고, 이들의 예측을 활용한 다양한 방식의 uncertainty 추정 방법을 비교하고자 한다.
먼저 대조군으로는 uncertainty penalty를 적용하지 않는 기본 Reward Model과, 하나의 Predictor와 RM hidden state 사이의 오차를 uncertainty로 사용하는 기존 Caution 방법을 사용한다.

제안 방법에서는 (n)개의 Predictor를 학습한 뒤 세 가지 방식으로 uncertainty를 계산한다. 첫 번째 방법은 여러 Predictor가 예측한 hidden state의 평균을 구한 뒤, 이 평균과 RM의 실제 hidden state 사이의 차이를 uncertainty로 사용하는 것이다. 
두 번째 방법은 각 Predictor의 예측값과 RM hidden state 사이의 오차를 각각 계산한 후, 이 오차들의 제곱평균제곱근(Root Mean Square, RMS)을 uncertainty로 사용한다. 
세 번째 방법은 RM의 hidden state와 직접 비교하지 않고, Predictor들의 예측값 사이의 표준편차를 이용하여 Predictor 간 disagreement 자체를 uncertainty로 사용한다.

이러한 방법들을 Best-of-N 환경에서 비교함으로써, 여러 Predictor를 활용한 ensemble 기반 uncertainty 추정이 기존의 단일 Predictor 기반 Caution보다 Reward Hacking을 더 효과적으로 완화할 수 있는지 확인하고자 한다.
