## 1. 정규표현식

기존 노트: [[Regular expressions]]

**핵심 키워드:** 문자 집합, 선택, 반복, 앵커, 단어 경계, 캡처 그룹, 치환, lookahead, false positive, false negative.

### 1.1 무엇을 하는가

정규표현식은 문자열의 형태를 패턴으로 기술하는 방법이다. NLP에서는 텍스트에서 특정 표현을 찾거나, 불필요한 부분을 제거하거나, 일정한 형식으로 치환할 때 사용한다.

매칭 결과를 구할 때는 ‘문장 전체가 조건을 만족하는가’와 ‘문장 안에서 조건을 만족하는 부분을 찾는가’를 구분한다. 첫 번째 결과만 찾는지, 모든 결과를 찾는지도 문제 조건을 확인한다.

### 1.2 기본 기호

아래 표의 백슬래시는 정규표현식 자체의 표기다. 프로그래밍 언어의 일반 문자열 안에 넣을 때 필요한 추가 이스케이프와 구분한다.

| 패턴       | 의미                        | 예시                              |
| -------- | ------------------------- | ------------------------------- |
| `[abc]`  | a, b, c 중 한 문자            | `[tT]he`는 `the`, `The`에 매칭      |
| `[A-Z]`  | 영문 대문자 한 문자               | `ABC`에서 각 대문자                   |
| `[^A-Z]` | 영문 대문자가 아닌 한 문자           | 소문자, 숫자, 공백 등도 포함               |
| `.`      | 기본적으로 줄바꿈을 제외한 임의의 한 문자   | `a.c`는 `abc`, `a-c`에 매칭         |
| `\.`     | 실제 온점                     | `end.`의 마지막 온점                  |
| `?`      | 바로 앞 요소가 0회 또는 1회         | `me?` → `m`, `me`               |
| `*`      | 바로 앞 요소가 0회 이상            | `to*` → `t`, `to`, `too`, …     |
| `+`      | 바로 앞 요소가 1회 이상            | `to+` → `to`, `too`, …          |
| `^`      | 문자열 시작                    | `^[A-Z]`는 시작 위치의 대문자            |
| `$`      | 문자열 끝의 경계                 | `\.$`는 끝 위치의 온점                 |
| `\b`     | 단어 문자와 비단어 문자 사이 등의 단어 경계 | `\bthe\b`는 `there` 안의 `the`를 제외 |

선택 연산자 `|`는 문자열 사이의 OR를 나타낸다. `cat|dog`는 `cat` 또는 `dog`를 뜻하며, 한 문자만 고르는 `[cat]`와 다르다.

`^`는 대괄호 밖에서 시작 앵커이고, 문자 집합의 맨 앞에서는 부정이다. `[e^]`는 `e` 또는 `^` 한 문자를 뜻한다. `[^A-Z]`가 ‘대문자를 포함하지 않는 단어 전체’를 뜻하는 것은 아니다.

수업 표의 별칭은 다음처럼 기억한다.

| 별칭         | 기본 의미                |
| ---------- | -------------------- |
| `\d`, `\D` | 숫자 / 숫자가 아닌 문자       |
| `\w`, `\W` | 단어 문자 / 단어 문자가 아닌 문자 |
| `\s`, `\S` | 공백류 / 공백류가 아닌 문자     |

영문 ASCII 예제에서는 `\d`를 `[0-9]`, `\w`를 `[A-Za-z0-9_]`처럼 생각할 수 있다. 실제 Unicode 처리와 줄바꿈·앵커의 세부 동작은 엔진과 옵션에 따라 달라진다. 예를 들어 Python의 Unicode 문자열에서 `\w`에는 한글 등도 포함될 수 있다.

### 1.3 반복의 범위와 greedy matching

`ab+`는 a 뒤에 b가 한 번 이상 나오는 패턴이다. `ab` 전체를 반복하려면 `(ab)+`처럼 묶어야 한다. 기본적인 `*`, `+`는 가능한 한 길게 매칭하는 greedy 방식이다. `+?`, `*?`와 같은 표기를 지원하는 엔진에서는 짧게 매칭하도록 바꿀 수 있다.

예를 들어 `a123b456b`에서 `a.*b`는 전체 문자열을 매칭한다. `a.*?b`는 첫 번째 b까지인 `a123b`를 매칭한다.

### 1.4 캡처 그룹과 치환

`(...)`는 내용을 묶고 매칭된 부분을 캡처한다. `(?:...)`는 묶되 캡처 번호를 만들지 않는 non-capturing group이다.

```text
입력: the 35 boxes
검색 패턴: ([0-9]+)
치환 표현: <\1>
결과: the <35> boxes
```

`\1`은 첫 번째 캡처 그룹에 해당하는 문자열을 다시 사용한다. 치환 구문은 도구마다 달라서 `\1` 대신 `$1` 등을 쓰기도 한다. 수업의 `s/패턴/치환/` 표기에서는 문제에서 제시한 문법을 따른다.

### 1.5 Lookahead

Lookahead는 **현재 위치 뒤의 문자열이 조건을 만족하는지 검사하고, 검사한 문자열 자체는 소비하지 않는** zero-width assertion이다.

| 패턴       | 뜻                 | 예시                                 |
| -------- | ----------------- | ---------------------------------- |
| `X(?=Y)` | X 바로 다음에 Y가 있어야 함 | `cat(?=s)`는 `cats`에서 `cat`만 매칭     |
| `X(?!Y)` | X 바로 다음에 Y가 없어야 함 | `cat(?!s)`는 `cats`의 `cat`에 매칭하지 않음 |

`^(?!Volcano)[A-Za-z]+`는 문자열 시작에서 `Volcano`라는 접두사가 없는지 검사한 후 영문자들을 매칭한다. ‘문자열 어디에도 Volcano가 없어야 한다’는 조건과는 다르다. 또한 `[A-z]`는 영문자 이외의 일부 기호까지 포함하므로 영문자만 원하면 `[A-Za-z]`로 쓴다.

### 1.6 오탐과 미탐

- **False positive:** 찾으면 안 되는 부분을 찾음. 단어 `the`만 원했는데 `there` 안의 `the`도 찾는 경우.
- **False negative:** 찾아야 하는 부분을 놓침. `the`만 사용하여 대문자로 시작하는 `The`를 놓치는 경우.

예를 들어 문장 `The cat is there. the dog sleeps.`에서 `[tT]he`는 `The`, `there`의 앞부분 `the`, 독립된 `the`를 찾는다. `\b[tT]he\b`는 독립된 `The`와 `the`만 찾는다.

**풀이 순서:** 문자 집합과 그룹을 구분 → 반복 기호의 적용 범위 확인 → 앵커·경계·lookahead 확인 → 왼쪽부터 실제 매칭 결과 추적.

## 2. 토큰화와 BPE

기존 노트: [[Word Tokenization]]

**핵심 키워드:** token, type, vocabulary, word-level, character-level, subword, BPE, pair frequency, merge, WordPiece.

### 2.1 왜 토큰화하는가

토큰화는 텍스트를 모델이 처리할 단위로 나누는 과정이다. **Token**은 실제 등장한 단위 한 개이고, **type**은 서로 다른 종류이며, **vocabulary**는 사용할 토큰 종류의 집합이다. `cat cat dog`는 단어 기준 token 3개, type 2개다.

| 방식      | 장점                           | 한계                       |
| ------- | ---------------------------- | ------------------------ |
| 단어 단위   | 익숙한 의미 단위와 가까움               | 어휘가 커지고 처음 보는 단어에 취약     |
| 문자 단위   | 기본 어휘가 작고 새로운 철자 조합을 표현하기 쉬움 | 시퀀스가 길고 단어 의미를 조합해 배워야 함 |
| 서브워드 단위 | 어휘 크기와 표현 범위를 절충             | 분할 결과가 항상 형태소와 일치하지는 않음  |

공백만으로 단어를 나누는 방법은 중국어·일본어 등에서 한계가 있다. Subword는 `wanted`를 `want`, `ed`처럼 표현할 수 있지만, BPE가 반드시 이런 언어학적 분할을 찾아준다는 뜻은 아니다.

### 2.2 BPE 학습

수업 예제처럼 단어별 빈도와 문자 분할에서 시작한다고 가정한다.

1. 등장한 문자들을 초기 vocabulary에 넣는다.
2. 현재 분할에서 서로 이웃한 토큰 쌍의 빈도를 센다.
3. 가장 빈번한 쌍 하나를 선택하여 새 토큰으로 병합한다.
4. 선택한 쌍을 모든 단어의 해당 위치에 반영하고 vocabulary에 새 토큰을 추가한다.
5. 변경된 분할을 기준으로 쌍 빈도를 다시 세고 반복한다.

쌍 빈도는 그 쌍이 등장하는 **단어 종류 수가 아니라 실제 등장 횟수**다. 단어 빈도가 5이면 그 단어의 각 인접 쌍도 5회씩 기여한다. 같은 단어 안에 같은 쌍이 여러 위치에 나오면 각 위치도 센다. 병합은 통상 겹치지 않게 적용하며, 겹치는 경우나 동률의 처리 규칙은 문제 조건을 따른다.

### 2.3 두 번 병합하는 예제

아래는 개념 확인용 작은 예제다. 단어 사이를 가로지르는 쌍은 세지 않는다.

| 단어 | 빈도 | 초기 분할 |
|---|---:|---|
| low | 5 | `l o w` |
| lower | 2 | `l o w e r` |
| new | 1 | `n e w` |

초기 vocabulary는 `{l, o, w, e, r, n}`이다. 주요 쌍의 빈도는 `(l,o)=7`, `(o,w)=7`, `(w,e)=2`, `(e,r)=2`, `(n,e)=1`, `(e,w)=1`이다.

동률이면 왼쪽 표에서 먼저 만나는 쌍을 고른다고 **이 예제에서만** 정하자.

| 단계 | 선택한 쌍 | low | lower | new | 새 토큰 |
|---|---|---|---|---|---|
| 초기 | — | `l o w` | `l o w e r` | `n e w` | — |
| 1회 | `(l,o)` | `lo w` | `lo w e r` | `n e w` | `lo` |
| 2회 | `(lo,w)` | `low` | `low e r` | `n e w` | `low` |

2회 뒤 vocabulary는 `{l, o, w, e, r, n, lo, low}`다. 기존 문자 토큰을 지우지 않는다. ‘2회 병합’은 병합 규칙을 두 번 선택했다는 뜻이며, 각 규칙은 해당하는 모든 단어에 적용된다.

**기출 풀이 체크:** 단어 빈도 곱하기, 병합 뒤 빈도 재계산, 최종 분할과 누적 vocabulary 구분, 동률 처리 조건, 단어 끝 기호의 유무.

### 2.4 BPE와 WordPiece 구분

기존 노트의 ‘2nd 방법’은 WordPiece의 교육용 설명에 해당한다. 두 방법을 BPE의 같은 선택 규칙으로 외우면 안 된다.

| 구분 | BPE | 수업 노트의 WordPiece 방식 |
|---|---|---|
| 병합 기준 | 인접 쌍의 빈도 | 아래의 정규화된 쌍 점수 |
| 새 입력 처리 | 학습한 병합 규칙을 순서대로 적용 | vocabulary에서 가장 긴 앞부분을 찾으며 분할 |
| `##` | 필수 표기 아님 | 단어 내부 조각임을 나타내는 BERT식 표기 |

$$
\operatorname{score}(a,b)=\frac{\operatorname{freq}(a,b)}{\operatorname{freq}(a)\operatorname{freq}(b)}
$$

WordPiece는 현재 남은 문자열의 **앞에서부터 가능한 가장 긴 토큰**을 선택하고 다음 조각으로 이동한다. 전형적인 BERT WordPiece에서는 끝까지 분할할 수 없으면 그 단어 전체를 `[UNK]`로 처리한다. BPE의 새 단어 분할은 학습 때 정한 병합 순서를 따르며, 새 문장에서 빈도를 다시 학습하지 않는다.

점수식에 의한 WordPiece 학습 설명은 Hugging Face의 교육용 재구성이다. 실제 구현마다 세부가 달라질 수 있으며 계산 문제에서는 수업에서 제시한 규칙을 따른다. [BPE 설명](https://huggingface.co/learn/llm-course/en/chapter6/5), [WordPiece 설명](https://huggingface.co/learn/llm-course/en/chapter6/6)

## 3. N-gram 언어 모델

기존 노트: [[N-gram Language Modeling]]

**핵심 키워드:** language model, conditional probability, chain rule, Markov assumption, unigram, bigram, trigram, MLE, log probability, perplexity, train/dev/test.

### 3.1 언어 모델과 연쇄법칙

언어 모델은 다음 토큰의 확률분포를 구하고, 이를 이용해 토큰 시퀀스의 확률을 계산한다. 단어들의 순서를 포함한 시퀀스를 $w_{1:T}$로 쓰자.

$$
P(w_{1:T})=\prod_{t=1}^{T}P(w_t\mid w_{1:t-1})
$$

예를 들어 $P(a,b,c)=P(a)P(b\mid a)P(c\mid a,b)$다. 이것은 확률의 연쇄법칙이고, 아직 문맥을 줄이는 근사는 하지 않았다.

### 3.2 Markov 가정과 N-gram

과거의 모든 단어를 조건으로 삼으면 가능한 문맥이 너무 많고 관측 자료가 부족하다. N-gram 모델은 직전 $N-1$개 토큰만으로 다음 토큰의 확률을 근사한다.

$$
P(w_t\mid w_{1:t-1})\approx P(w_t\mid w_{t-N+1:t-1})
$$

| 모델 | 조건으로 보는 과거 | 예측 확률 |
|---|---|---|
| Unigram | 없음 | $P(w_t)$ |
| Bigram | 직전 1개 | $P(w_t\mid w_{t-1})$ |
| Trigram | 직전 2개 | $P(w_t\mid w_{t-2},w_{t-1})$ |

N은 **예측할 현재 토큰까지 포함한 길이**다. 따라서 bigram이 이전 단어 두 개를 본다는 해석은 틀리다. Bigram 모델 아래에서는 $P_{\text{bigram}}(w_{1:T})=\prod_tP(w_t\mid w_{t-1})$로 계산하지만, 이것이 실제 언어의 전체 문맥 확률과 정확히 같다고 가정하는 것은 아니다.

### 3.3 MLE로 조건부확률 계산

$$
\hat P(w\mid h)=\frac{C(h,w)}{\sum_{v\in V}C(h,v)}
$$

$h$는 문맥이다. 분자는 ‘문맥 다음에 목표 단어가 나온 횟수’, 분모는 ‘그 문맥 뒤에 예측 대상 토큰이 나온 총횟수’다. Bigram에서는 보통 $C(w_{t-1},w_t)/C(w_{t-1})$로 쓰되, 문장 경계의 집계 규칙이 일관되어야 한다.

문장 시작은 `<s>`, 끝은 `</s>`로 표시할 수 있다. `<s>`는 초기 조건이고 보통 예측 대상으로 세지 않는다. `</s>`는 문장 종료를 예측할 때 포함한다. Trigram의 시작 문맥에는 시작 기호 두 개를 둘 수도 있다. 시험에서 주어진 표기법을 따른다.

### 3.4 문장 확률 계산 예제

학습 문장이 다음 세 개라고 하자.

```text
<s> i like nlp </s>
<s> i like math </s>
<s> you like nlp </s>
```

Bigram으로 첫 번째 문장에 확률을 부여하면 다음과 같다.

$$
P(i\mid\texttt{<s>})P(like\mid i)P(nlp\mid like)P(\texttt{</s>}\mid nlp)
=\frac23\times\frac22\times\frac23\times\frac22=\frac49
$$

분모는 전체 단어 수가 아니다. 예를 들어 $P(nlp\mid like)$의 분모는 `like` 뒤에 토큰이 이어진 횟수 3이다.

관측되지 않은 전이의 MLE는 0이다. 문장 확률은 여러 항의 곱이므로 한 항만 0이어도 전체가 0이 된다. Smoothing이 이를 완화하지만, 문제에서 지시하지 않은 smoothing을 임의로 적용하지 않는다. 기존 정리에서 add-1을 구체적으로 다룬 단원은 Naive Bayes다.

### 3.5 로그 확률

$$
\log P(w_{1:T})=\sum_{t=1}^{T}\log P(w_t\mid h_t)
$$

작은 확률을 계속 곱할 때 발생하는 수치적 underflow를 줄이고 곱을 합으로 바꿀 수 있다. 로그는 증가함수이므로 확률이 큰 후보와 로그 확률이 큰 후보의 순서는 같다. 단, 음의 로그인 NLL은 작을수록 좋다.

### 3.6 평가와 perplexity

- **Train:** 모델의 빈도나 파라미터를 학습한다.
- **Dev/validation:** 모델 선택과 하이퍼파라미터 조정에 활용한다.
- **Test:** 선택이 끝난 모델의 최종 성능을 평가한다. 반복적으로 보고 튜닝하면 평가의 독립성이 약해진다.
- **Intrinsic evaluation:** 언어 모델 자체의 예측 성능을 perplexity 등으로 평가한다.
- **Extrinsic evaluation:** 모델을 실제 번역·음성인식 등의 작업에 넣고 최종 작업 성능으로 평가한다. 단순히 ‘두 모델을 비교하는 것’이라는 뜻은 아니다.

예측 대상 토큰 수를 $T$라고 하면 다음과 같다.

$$
PP(W)=P(W)^{-1/T}
=\exp\left(-\frac1T\sum_{t=1}^{T}\ln P(w_t\mid h_t)\right)
$$

밑 2의 로그를 쓰면 $PP=2^{H}$이고, $H=-\frac1T\sum_t\log_2P(w_t\mid h_t)$다. 같은 평가 데이터와 토큰화·어휘 처리 조건에서는 정답 토큰에 높은 확률을 부여할수록 PP가 낮다. 서로 다른 토큰화의 PP를 그대로 비교하면 안 된다.

예를 들어 예측 대상이 4개이고 문장 확률이 $1/16$이면 $PP=(1/16)^{-1/4}=2$다. 종료 토큰을 확률에 포함했다면 토큰 수를 셀 때도 문제의 평가 관례에 맞춰 포함한다.

N-gram의 한계는 제한된 문맥 때문에 장거리 의존성을 놓치고, 처음 보는 조합이나 의미가 비슷한 다른 단어로 일반화하기 어렵다는 점이다. 데이터 누수는 평가를 부풀릴 수 있지만 성능이 높다는 사실만으로 누수가 입증되지는 않는다.

## 4. Naive Bayes와 분류 평가

기존 노트: [[Naive Bayes]]

**핵심 키워드:** supervised classification, Bayes rule, prior, likelihood, posterior, MAP, bag of words, conditional independence, MLE, Laplace smoothing, OOV, confusion matrix, precision, recall, F1, micro/macro.

### 4.1 문서 분류와 Bayes 규칙

문서 분류는 입력 문서 $d$를 정해진 클래스 집합 $C$ 중 하나로 분류하는 작업이다. 직접 작성한 규칙을 사용할 수도 있고, 정답 레이블이 있는 문서로 지도학습을 할 수도 있다.

$$
P(c\mid d)=\frac{P(d\mid c)P(c)}{P(d)}
$$

| 확률           | 이름         | 의미                      |
| ------------ | ---------- | ----------------------- |
| $P(c)$       | Prior      | 문서를 보기 전 클래스의 확률        |
| $P(d\mid c)$ | Likelihood | 클래스가 c일 때 해당 문서가 나타날 확률 |
| $P(c\mid d)$ | Posterior  | 문서를 본 뒤 클래스가 c일 확률      |

$$
\hat c=\arg\max_{c\in C}P(c\mid d)
=\arg\max_{c\in C}P(c)P(d\mid c)
$$

같은 문서를 클래스별로 비교하므로 $P(d)$가 공통이다. 분류할 클래스만 고를 때는 생략할 수 있지만, **정규화된 posterior 값 자체**를 요구하면 다시 정규화해야 한다.

### 4.2 무엇이 naive한가

Bag-of-words 가정은 단어 순서와 위치를 무시한다. 조건부 독립 가정은 클래스가 주어졌을 때 각 단어 출현의 확률을 독립적으로 곱할 수 있다고 보는 것이다. 두 가정을 구분해서 설명해야 한다.

Multinomial Naive Bayes의 분류 점수는 다음과 같다.

$$
s_c=P(c)\prod_{i=1}^{L}P(x_i\mid c)
$$

$$
\log s_c=\log P(c)+\sum_{i=1}^{L}\log P(x_i\mid c)
$$

표준 multinomial 방식에서는 문서에 같은 단어가 3번 나오면 그 단어 확률도 3번 곱한다. 단어 빈도 벡터로 적으면 $\prod_{w\in V}P(w\mid c)^{C(w,d)}$다. 엄밀한 bag count 확률의 multinomial 계수는 같은 문서의 클래스 비교에서 공통이므로 분류 점수에서는 생략할 수 있다.

### 4.3 Prior와 likelihood의 분모

$$
\hat P(c)=\frac{\text{클래스 c의 학습 문서 수}}{\text{전체 학습 문서 수}}
$$

$$
\hat P(w\mid c)=\frac{C(w,c)}{N_c},\qquad N_c=\sum_{v\in V}C(v,c)
$$

Prior는 **문서 수**, likelihood는 **단어 token 수**로 센다. $|V|$는 전체 학습 어휘의 서로 다른 type 수다. 클래스마다 별도의 $|V|$를 임의로 사용하지 않는다.

### 4.4 Add-1 smoothing

어떤 단어가 특정 클래스에서 한 번도 나오지 않으면 MLE가 0이 된다. 이를 완화하기 위해 모든 어휘 항목의 count에 1씩 더한다.

$$
\hat P(w\mid c)=\frac{C(w,c)+1}{N_c+|V|}
$$

분모에도 어휘 항목 수만큼 더해야 전체 확률의 합이 1이 된다. ‘등장하지 않은 단어에만 1을 더하는 것’이 아니다. 일반적인 add-$\alpha$는 $(C(w,c)+\alpha)/(N_c+\alpha|V|)$다. Prior의 smoothing 여부는 별도 조건이므로 단어 확률에 smoothing을 한다고 prior까지 자동으로 바꾸지 않는다.

### 4.5 계산 예제

| 클래스 | 학습 문서 |
|---|---|
| + | `good fun` |
| + | `good good` |
| − | `bad boring` |
| − | `bad bad` |

$V=\{good,fun,bad,boring\}$이므로 $|V|=4$, $N_+=N_-=4$, $P(+)=P(-)=1/2$다. `good fun`을 분류하자.

| 단어 | +의 count | −의 count | $P(w\mid +)$ | $P(w\mid -)$ |
|---|---:|---:|---|---|
| good | 3 | 0 | $(3+1)/8=1/2$ | $(0+1)/8=1/8$ |
| fun | 1 | 0 | $(1+1)/8=1/4$ | $(0+1)/8=1/8$ |

$$
s_+=\frac12\cdot\frac12\cdot\frac14=\frac1{16},\qquad
s_-=\frac12\cdot\frac18\cdot\frac18=\frac1{128}
$$

큰 점수를 가지는 +로 분류한다. 이 점수 자체가 posterior는 아니다. 정규화된 값까지 구하면 $P(+\mid d)=\frac{s_+}{s_++s_-}=8/9$다.

**풀이 순서:** 학습 vocabulary 확정 → 문서 수로 prior → 클래스별 token 수 → 단어 count → smoothing → 문서 내 반복 횟수를 반영하여 점수 계산 → 비교 또는 정규화.

### 4.6 Unknown word와 전처리

- **OOV:** 전체 학습 vocabulary에 없는 단어다. 복기본의 예제처럼 고정 vocabulary 밖 단어를 무시하는 설정에서는 계산에서 제외한다. `<UNK>`를 둔 모델에서는 그 확률을 사용한다.
- **특정 클래스에서만 미등장:** 전체 vocabulary에는 있는 단어이므로 OOV가 아니다. 해당 클래스의 count 0에 smoothing을 적용한다.
- **Stop words:** 자주 등장하는 기능어 등이다. 제거는 선택 사항이며, 감성 분류에서는 제거가 오히려 성능을 낮출 수 있다. ‘항상 의미가 없어서 지운다’고 외우지 않는다.
- **Binary multinomial NB:** 학습과 예측에서 문서별 중복을 제거하여 같은 단어를 한 문서에서 한 번만 센다. 단어 부재 확률까지 쓰는 Bernoulli NB와는 구분한다.
- **Negation:** 예를 들어 부정어 다음부터 구두점까지 `NOT_` 접두사를 붙여 `good`과 `NOT_good`을 다른 특징으로 만든다. 적용 범위는 전처리 규칙에 따른다.
- **Lexicon:** 단어의 감성·의미 같은 정보를 모은 사전이다. 문서 레이블이 붙은 학습 corpus와 같은 뜻은 아니다.

Unigram LM과 multinomial NB는 모두 단어 확률의 곱을 활용한다. 다만 NB는 **클래스마다 다른 단어 분포 $P(w\mid c)$**와 클래스 prior를 사용하여 분류한다. 차이를 단순히 ‘prior의 유무’로만 설명하면 불충분하다.

### 4.7 Confusion matrix와 평가 지표

| 실제 / 예측     | Positive로 예측 | Negative로 예측 |
| ----------- | ------------ | ------------ |
| 실제 Positive | TP           | FN           |
| 실제 Negative | FP           | TN           |

True/false는 예측의 정오, positive/negative는 예측한 쪽을 가리킨다. 특히 FN은 ‘실제 positive를 negative로 예측하여 놓친 경우’다.

$$
Accuracy=\frac{TP+TN}{TP+FP+TN+FN}
$$

$$
Precision=\frac{TP}{TP+FP},\qquad Recall=\frac{TP}{TP+FN}
$$

$$
F_1=\frac{2PR}{P+R}=\frac{2TP}{2TP+FP+FN}
$$

Precision은 ‘positive라고 예측한 것 중 맞은 비율’, recall은 ‘실제 positive 중 찾아낸 비율’이다. F1은 두 값의 조화평균이다. 클래스가 불균형하면 다수 클래스만 예측해도 accuracy가 높을 수 있다. 분모가 0인 지표의 처리 방식은 문제 조건이나 평가 도구의 정의를 따른다.

다중 클래스에서는 각 클래스를 positive, 나머지 전체를 negative로 두는 **one-vs-rest**로 TP·FP·FN을 계산할 수 있다. 클래스를 두 개씩 짝짓는 방식과 구분한다.

- **Micro:** 클래스별 TP·FP·FN을 합산한 다음 지표를 계산한다. 표본 수가 많은 클래스의 영향이 크다.
- **Macro:** 클래스별 지표를 먼저 계산하고 산술평균한다. 클래스마다 같은 비중이다.

Macro-F1은 **클래스별 F1의 평균**이다. Macro-precision과 macro-recall을 먼저 평균낸 뒤 그 둘의 F1을 계산한 값과 일반적으로 같지 않다.

## 5. 신경망과 경사하강법

기존 노트: [[Neural Network]]

**핵심 키워드:** weight, bias, activation, forward pass, loss, partial derivative, gradient descent, learning rate, batch, SGD, mini-batch, epoch.

### 5.1 뉴런의 계산

$$
z=\sum_iw_ix_i+b,\qquad y=f(z)
$$

입력 $x$를 weight로 가중합하고 bias를 더한 뒤 activation을 통과시킨다. Bias는 입력이 0일 때도 출력의 기준을 이동시킬 수 있게 한다. 비선형 activation이 없으면 여러 affine layer를 쌓아도 하나의 affine 변환으로 합쳐진다.

기존 노트의 $\partial y/\partial w_i=x_i$는 **출력이 선형인 경우**에 맞는다. Activation이 있으면 다음과 같다.

$$
\frac{\partial y}{\partial w_i}=f'(z)x_i
$$

예를 들어 sigmoid $\sigma(z)=1/(1+e^{-z})$의 도함수는 $\sigma(z)(1-\sigma(z))$다. 문제에 activation이 주어졌는지 먼저 확인한다. 아래의 기출 연결 계산은 선형 출력을 가정한다.

### 5.2 손실함수와 미분

회귀 예제의 squared error는 다음과 같다.

$$
\mathcal L=(y-y^*)^2
$$

$$
\frac{\partial\mathcal L}{\partial y}=2(y-y^*),\qquad
\frac{\partial\mathcal L}{\partial w_i}=2(y-y^*)x_i
$$

Bias가 학습 대상이면 $\partial\mathcal L/\partial b=2(y-y^*)$다. 손실에 $1/2$가 붙으면 미분의 2가 상쇄되고, 평균을 내는 손실이면 평균 계수도 반영한다. 문제의 손실식을 그대로 미분해야 한다.

### 5.3 경사하강법의 업데이트

$$
w_i^{new}=w_i-\eta\frac{\partial\mathcal L}{\partial w_i}
$$

$\eta>0$는 learning rate다. 기울기는 함수가 증가하는 방향을 가리키므로 손실을 줄이기 위해 반대 방향으로 이동한다. 기울기가 음수면 해당 가중치는 증가한다.

한 번의 업데이트에서는 모든 gradient를 **같은 현재 파라미터**로 계산하고 모든 가중치를 함께 갱신한다. $w_0$를 먼저 바꾼 값을 이용해 같은 iteration의 $w_1$ 기울기를 다시 계산하면 일반적인 gradient descent와 다른 계산이 된다.

### 5.4 기출 이미지와 연결되는 표 계산

조건은 $x_0=4$, $x_1=2$, $y^*=5$, $\eta=0.01$, 초기 $w_0=w_1=0$이며 bias와 activation은 없다고 하자.

$$
y=4w_0+2w_1,\quad \mathcal L=(y-5)^2
$$

$$
\frac{\partial\mathcal L}{\partial w_0}=8(y-5),\qquad
\frac{\partial\mathcal L}{\partial w_1}=4(y-5)
$$

아래의 각 행은 해당 횟수만큼 갱신한 뒤의 파라미터·출력·손실이다.

| 갱신 횟수 | $w_0$ | $w_1$ | $y$ | $\mathcal L$ |
|---:|---:|---:|---:|---:|
| 0 | 0 | 0 | 0 | 25 |
| 1 | 0.4 | 0.2 | 2 | 9 |
| 2 | 0.64 | 0.32 | 3.2 | 3.24 |
| 3 | 0.784 | 0.392 | 3.92 | 1.1664 |

예를 들어 1회 갱신 뒤에는 $y=2$이므로 기울기가 각각 $-24$, $-12$다. 다음 가중치는 $0.4-0.01(-24)=0.64$, $0.2-0.01(-12)=0.32$가 된다.

**표 풀이 순서:** 현재 weight로 y → 현재 loss → 모든 gradient → weight 동시 갱신 → 다음 행의 y와 loss.

### 5.5 업데이트에 사용하는 데이터의 크기

| 방법 | 한 번의 업데이트에 사용하는 데이터 |
|---|---|
| Batch GD | 전체 training set |
| SGD | 한 표본 |
| Mini-batch GD | 여러 표본으로 구성된 작은 batch |

SGD는 표본별 잡음 때문에 경로가 흔들릴 수 있다. Mini-batch는 계산 효율과 gradient 추정의 변동을 절충한다. **Epoch**는 training set 전체를 한 번 사용하는 주기이고, **iteration/step**은 보통 한 번의 업데이트를 뜻한다. 데이터 M개, batch 크기 B이면 한 epoch의 step 수는 마지막 불완전 batch를 포함하는 경우 $\lceil M/B\rceil$이다.

학습률이 너무 크면 진동하거나 발산할 수 있고 너무 작으면 느리게 학습한다. 학습률 감소의 예는 $\eta_e=\eta_0/(1+\omega e)$다. 감소 스케줄이 local minimum 탈출이나 최적해 도달을 보장하는 것은 아니다.

## 6. 역전파

기존 노트: [[Neural Network]]

**핵심 키워드:** computational graph, chain rule, local derivative, path, gradient accumulation, output gradient, loss gradient.

### 6.1 연쇄법칙과 여러 경로

한 경로로 연결된 $w\to h\to y\to\mathcal L$에 대해서는 다음과 같다.

$$
\frac{\partial\mathcal L}{\partial w}
=\frac{\partial\mathcal L}{\partial y}
\frac{\partial y}{\partial h}
\frac{\partial h}{\partial w}
$$

여러 경로가 있으면 각 경로에서는 미분을 곱하고, 서로 다른 경로의 기여를 더한다. 예를 들어 x가 $h_1$, $h_2$를 거쳐 y에 영향을 주면 다음과 같다.

$$
\frac{\partial y}{\partial x}
=\frac{\partial y}{\partial h_1}\frac{\partial h_1}{\partial x}
+\frac{\partial y}{\partial h_2}\frac{\partial h_2}{\partial x}
$$

Backpropagation은 이 연쇄법칙을 출력 쪽부터 적용하여 중간 gradient를 재사용하는 계산 절차다. 먼저 forward pass로 중간값을 구하고, backward pass로 미분을 전달하고, 마지막에 파라미터를 갱신한다.

### 6.2 기출 그림의 특정 가중치 미분

복기본 그림의 가중치 $w^0_{00}$에서 출력으로 가는 경로만 보자. 그림처럼 비선형 activation 없이 가중합한다고 가정하면 관련 식은 다음과 같다.

$$
h_{10}=w^0_{00}x_0+\text{다른 입력의 항}
$$

$$
h_{20}=4h_{10}+5h_{11},\quad
h_{21}=1h_{10}+2h_{11},\quad
y=2h_{20}+6h_{21}
$$

$x_0=3$이고 $h_{11}$은 이 특정 가중치에 의존하지 않는다. 두 경로를 모두 더하면 다음과 같다.

$$
\frac{\partial y}{\partial w^0_{00}}
=3\cdot4\cdot2+3\cdot1\cdot6=24+18=42
$$

한 경로의 가중치 곱만 구하면 다른 경로의 영향을 빠뜨린다. 다른 입력의 가중치 값이 없어도 이 편미분은 계산할 수 있다.

### 6.3 출력의 미분과 손실의 미분 구분

복기본 그림에는 $w^{new}=w-\eta\,\partial y/\partial w$가 제시되어 있다. 그 식을 그대로 적용하면 다음과 같다.

$$
(w^0_{00})^{new}=3-0.01\cdot42=2.58
$$

**그림의 2.38은 산술 오타다.** $3-0.42=2.58$이다.

일반적인 신경망 학습은 출력 y 자체가 아니라 **손실을 최소화**하므로 $\partial\mathcal L/\partial w$를 사용한다. 손실이 $(y-y^*)^2$라면 다음 항까지 곱해야 한다.

$$
\frac{\partial\mathcal L}{\partial w^0_{00}}
=2(y-y^*)\cdot42
$$

출력의 미분만 주어진 예제와 손실의 미분을 요구하는 문제를 구분한다. 손실 기준 업데이트를 수치로 구하려면 필요한 y와 정답 등의 조건도 있어야 한다. Activation이 있으면 경로별로 activation의 도함수도 포함한다.

**풀이 순서:** 미분할 대상 확인 → 목표가 y인지 loss인지 확인 → 해당 변수에서 목표까지의 모든 경로 확인 → 경로별 미분 곱 → 경로 기여 합산 → 주어진 업데이트 식 적용.

## 7. 다중 분류 손실과 일반화

기존 노트: [[Neural Network]]

**핵심 키워드:** logit, softmax, one-hot label, cross-entropy, NLL, overfitting, underfitting, L2, weight decay, dropout.

### 7.1 Softmax

모델이 K개 클래스에 대해 내는 실수 점수 $z_1,\dots,z_K$를 logits라고 한다. 이 점수들을 클래스 확률로 바꾸는 함수가 softmax다.

$$
p_k=\operatorname{softmax}(z)_k
=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}
$$

각 확률은 양수이고 합은 1이다. 분모는 **모든 클래스 점수의 지수 합**이다. 기존 노트처럼 분모의 합 안을 $e^{z_k}$로 고정하면 잘못된 식이 된다. 가장 높은 logit의 클래스가 가장 높은 확률의 클래스다.

### 7.2 Cross-entropy와 NLL

정답 one-hot 벡터를 $t$, 예측 확률을 $p$라고 하자.

$$
\mathcal L=-\sum_{k=1}^{K}t_k\log p_k
$$

정답 클래스가 c이면 $t_c=1$, 나머지는 0이므로 다음과 같이 줄어든다.

$$
\boxed{\mathcal L=-\log p_c}
$$

Hard label의 cross-entropy는 정답 클래스에 대한 negative log-likelihood와 같다. **확률 전체를 그냥 더해서 로그를 취하는 식이 아니다.** 정답 클래스가 어느 것인지 먼저 확인한다.

예측이 $(0.1,0.7,0.2)$이고 정답이 두 번째 클래스라면 loss는 $-\ln0.7\approx0.3567$이다. 잘못된 첫 번째 클래스를 정답으로 사용하면 $-\ln0.1\approx2.3026$이 되어 다른 계산이다. 정답 확률이 커질수록 loss는 작아진다.

기출의 `[빈칸] log [빈칸]`은 식의 주어진 형식에 따라 음의 부호와 정답 클래스 확률, 또는 $-\sum_k t_k\log p_k$의 계수 부분을 구분하여 채운다. 실제 빈칸 배치가 복기되지 않았으므로 한 형태만 외우지 말고 두 식의 연결을 이해한다.

여러 표본의 손실은 보통 합이나 평균을 쓰므로 문제에서 요구한 방식을 따른다. 이진 분류에서는 $-\{t\log p+(1-t)\log(1-p)\}$이고, 위의 K-class 식과 표기 조건을 구분한다.

### 7.3 Overfitting과 underfitting

- **Overfitting:** 학습 데이터의 특이한 패턴이나 잡음까지 맞추어 학습 성능에 비해 새로운 데이터의 성능이 떨어지는 현상.
- **Underfitting:** 모델 표현력이나 학습이 부족하여 학습 데이터에서도 충분히 맞추지 못하는 현상.

Training loss가 낮다는 사실만으로 일반화 성능이 좋다고 할 수 없다. Dev set으로 일반화 경향과 설정을 점검하고, test set은 최종 평가에 사용한다.

### 7.4 L2 정규화

기존 노트의 표기대로 n을 학습 표본 수라고 하면 다음과 같다.

$$
C=C_0+\frac{\lambda}{2n}\sum_iw_i^2
$$

$$
\frac{\partial C}{\partial w_i}
=\frac{\partial C_0}{\partial w_i}+\frac\lambda n w_i
$$

$$
w_i^{new}=\left(1-\frac{\eta\lambda}{n}\right)w_i
-\eta\frac{\partial C_0}{\partial w_i}
$$

큰 가중치에 비용을 부과하여 학습 손실과 모델 복잡도 사이의 균형을 조절한다. 일반적인 gradient descent에서 위와 같은 축소 항이 생긴다. 정규화 계수에 n을 포함시키는지는 정의에 따라 달라지므로 주어진 목적함수와 일치시켜 미분한다. 모든 optimizer에서 L2와 별도의 weight decay가 완전히 같은 것은 아니다.

### 7.5 Dropout

학습 중 일부 뉴런의 출력을 무작위로 0으로 만들어 특정 뉴런 조합에 지나치게 의존하는 것을 줄이는 방법이다. 평가할 때도 같은 방식으로 무작위 삭제한다고 외우면 안 된다. 전형적인 inverted dropout은 학습 때 살아남은 출력을 유지 확률로 나누어 스케일을 맞추고, 평가 때는 dropout을 끈다.

## 8. 벡터 의미론과 임베딩

기존 노트: [[Vector Semantics and Embeddings - 중간]]

**핵심 키워드:** lemma, sense, polysemy, synonymy, similarity, relatedness, antonymy, connotation, distributional hypothesis, one-hot, sparse/dense, term-document, word-context, cosine, TF-IDF, PMI, static embedding.

복기본 7문제에는 직접 언급되지 않았지만 기존 중간 범위 정리에 포함된 내용이다. 먼저 아래 개념과 계산식을 복습하고, Word2vec의 세부 학습 절차는 수업 자료에서 범위를 추가 확인하기 전까지 확장하지 않는다.

### 8.1 단어의 의미 관계

| 개념             | 의미와 예                                                  |
| -------------- | ------------------------------------------------------ |
| Lemma          | 굴절형들을 대표하는 기본형. 예: `run`, `runs`, `ran`의 lemma는 `run`. |
| Sense          | 단어가 가지는 특정 의미. `bank`의 금융기관 의미와 강둑 의미처럼 구분.            |
| Polysemy       | 하나의 어휘 항목이 관련된 여러 의미를 가지는 다의성. 서로 무관한 의미의 동형어와는 구분 가능. |
| Synonymy       | 유사한 의미 관계. `big`, `large`도 모든 문맥에서 교체 가능한 것은 아님.       |
| Similarity     | 의미나 속성이 비슷함. `car`와 `bicycle`.                         |
| Relatedness    | 같은 상황·주제로 연관됨. `coffee`와 `cup`은 관련되지만 유사어는 아님.         |
| Semantic field | 하나의 의미 영역을 이루는 관련 어휘 집합.                               |
| Antonymy       | 반대 관계. `hot/cold`, `rise/fall` 등은 반대의 방식이 다를 수 있음.     |
| Connotation    | 지시적 의미와 별개로 느껴지는 감정·평가·뉘앙스.                            |

감정적 뉘앙스의 세 차원은 **valence**(쾌·불쾌), **arousal**(각성·진정), **dominance**(통제감·우세감)다. 이것은 의미 표현의 한 예시이며 모든 임베딩이 이 세 축으로만 이루어진다는 뜻은 아니다.

### 8.2 One-hot과 분포 가설

Vocabulary 크기가 $|V|$이면 one-hot은 해당 단어 위치만 1이고 나머지는 0인 $|V|$차원 벡터다. 서로 다른 단어의 one-hot 내적은 0이어서 의미 유사성이 직접 드러나지 않는다.

**분포 가설:** 비슷한 문맥에 등장하는 단어는 의미도 비슷한 경향이 있다. 분포를 이용해 벡터를 만들면 단어 사이의 유사성을 거리나 방향으로 나타낼 수 있다.

학습된 벡터가 있는 단어들 사이에서는 의미를 공유하여 처음 보는 조합에 일반화할 수 있다. 그러나 표준 Word2vec이 **어휘에 없는 새 단어의 벡터를 자동으로 만들어주는 것은 아니다.** 새로운 조합과 OOV 단어를 구분한다.

### 8.3 Count 기반 벡터

- **Term-document matrix:** 원소는 특정 단어가 특정 문서에 등장한 횟수다. 단어를 행으로 두었다면 행은 문서 분포로 표현한 단어 벡터, 열은 단어 분포로 표현한 문서 벡터다. 전치된 배치도 가능하다.
- **Word-context matrix:** 목표 단어 주변 window 안에 어떤 문맥 단어가 얼마나 등장했는지 센다. Window가 좌우 k칸이면 범위 밖 토큰은 세지 않는다.
- **Sparse vector:** 많은 좌표가 0이다. 문서나 어휘가 좌표가 되면 차원이 크다.
- **Dense vector:** 상대적으로 낮은 차원의 대부분 좌표에 값이 있다. 학습으로 여러 속성을 나누어 담을 수 있다.

### 8.4 Cosine similarity

$$
\cos(u,v)=\frac{u\cdot v}{\lVert u\rVert_2\lVert v\rVert_2}
$$

내적을 각 벡터의 길이로 나누어 방향의 유사성을 본다. 두 벡터가 0이 아니면 범위는 $[-1,1]$이며, 음수가 없는 count·TF-IDF 벡터에서는 $[0,1]$이다. Zero vector의 cosine은 이 식으로 정의되지 않는다.

예를 들어 $u=(1,1)$, $v=(1,0)$이면 내적은 1, 길이는 각각 $\sqrt2$, 1이므로 cosine은 $1/\sqrt2\approx0.7071$이다. 정규화하지 않은 내적은 벡터 크기의 영향도 받는다.

### 8.5 TF-IDF

한 문서에서 자주 등장하는 단어는 중요할 수 있지만, 모든 문서에 흔한 단어는 문서를 구분하는 힘이 약하다. TF는 문서 내부 빈도, IDF는 전체 문서에서의 희귀성을 반영한다.

$$
w_{t,d}=tf_{t,d}\times idf_t,\qquad
idf_t=\log_{10}\frac{D}{df_t}
$$

D는 전체 문서 수, $df_t$는 t가 한 번 이상 나온 **문서 수**다. 같은 문서에서 t가 10번 나와도 df에는 1만 기여한다.

Raw TF는 $tf_{t,d}=C(t,d)$이고, 수업 노트의 log TF는 다음과 같다.

$$
tf_{t,d}=\begin{cases}
1+\log_{10}C(t,d), & C(t,d)>0\\
0, & C(t,d)=0
\end{cases}
$$

D=100, $df_t=10$, $C(t,d)=100$이면 IDF=1, log TF=3, TF-IDF=3이다. Raw TF를 쓰면 같은 조건에서 100이다. 문제에서 어떤 TF와 로그 밑을 쓰는지 확인한다. 이 IDF 정의에서 모든 문서에 나오는 단어는 IDF가 0이고, 문서에 없는 단어의 TF-IDF는 0이다.

### 8.6 PMI

$$
PMI(w,c)=\log\frac{P(w,c)}{P(w)P(c)}
$$

독립이라면 예상되는 동시출현 확률과 실제 동시출현 확률을 비교한다. 양수면 독립일 때보다 더 자주, 0이면 독립일 때만큼, 음수면 더 드물게 함께 나온다. Count로 확률을 만들 때는 joint와 marginal이 같은 단어-문맥 관측 공간에서 정의되도록 한다.

예를 들어 $P(w,c)=0.02$, $P(w)=0.1$, $P(c)=0.1$이고 밑 2를 사용하면 $PMI=\log_2 2=1$이다. 동시출현이 0이면 로그가 유한하지 않으므로 별도 처리 규칙이 필요하다. PPMI는 음수를 0으로 자른 $\max(PMI,0)$이며, 수업에서 요구한 경우에 사용한다.

### 8.7 Word2vec의 기본 위치

TF-IDF나 문맥 count는 주로 고차원 sparse 표현을 만든다. Word2vec은 주변 단어를 예측하는 학습을 통해 상대적으로 낮은 차원의 dense 벡터를 얻는다. 기존 노트의 ‘후보 단어가 이웃인지 예측’은 그 학습 아이디어를 가리킨다.

**Word2vec은 static embedding이다.** 문맥을 이용해 학습하지만, 학습 뒤에는 같은 어휘 항목에 같은 벡터를 사용한다. 등장 문맥마다 다른 벡터를 내는 BERT 등의 contextual embedding과 구분한다. [임베딩 교재](https://web.stanford.edu/~jurafsky/slp3/5.pdf)

| 정규식 `[A-za-z]`                    | 영문자만 의도했다면 `[A-Za-z]`를 쓴다.                    |
| Extrinsic evaluation은 두 모델 비교     | 실제 응용 작업의 최종 성능으로 평가하는 방식이다.                  |
| Bag-of-words만으로 단어 확률의 곱 설명       | 순서 무시와 클래스 조건부 독립 가정을 구분한다.                   |
| Unknown words, stop words는 무조건 무시 | 전처리·vocabulary 조건에 따른다. 클래스별 미등장과 OOV도 구분한다.  |
| NB와 unigram의 차이는 prior뿐           | NB는 클래스별 단어 분포도 따로 학습한다.                      |
| 다중 클래스 평가는 클래스 두 개씩 선택            | 여기서의 지표 계산은 보통 one-vs-rest 후 micro/macro 집계다. |
| $\partial y/\partial w_i=x_i$     | 선형 출력일 때다. Activation이 있으면 도함수를 곱한다.          |
| Softmax 분모의 지수 항이 같은 인덱스          | 합의 인덱스가 움직이도록 $\sum_j e^{z_j}$로 쓴다.           |
| 역전파 이미지의 $3-0.42=2.38$            | 정확한 값은 2.58이다. 출력과 손실의 gradient도 구분한다.        |
| Word2vec은 contextual embedding    | 정적 임베딩이다. 문맥을 활용한 학습과 문맥별 출력은 다르다.            |
| 임베딩이면 모든 새 단어 처리 가능               | 학습 vocabulary 안의 단어에 대한 일반화와 OOV 처리는 구분한다.    |

## 10. 1단계 복습 완료 기준

각 단원을 읽은 뒤, 공식을 가리고 다음을 설명할 수 있으면 키워드 회상 단계로 넘어갈 준비가 된 것이다.

- [ ] 정규표현식의 각 기호를 해석하고, 매칭 결과와 캡처 결과를 구분할 수 있다.
- [ ] BPE의 쌍 빈도를 단어 빈도와 함께 세고, 병합 2회 뒤의 분할과 vocabulary를 적을 수 있다.
- [ ] N-gram의 문맥 길이와 MLE 분모를 설명하고 문장 확률을 계산할 수 있다.
- [ ] Log probability와 perplexity의 방향을 설명하고 train/dev/test의 역할을 구분할 수 있다.
- [ ] NB에서 문서 수·token 수·type 수를 구분하고 smoothing부터 최종 분류까지 계산할 수 있다.
- [ ] Precision, recall, F1과 micro/macro의 차이를 설명할 수 있다.
- [ ] Gradient descent의 표를 같은 현재 파라미터에 대한 gradient로 채울 수 있다.
- [ ] 역전파에서 모든 경로를 더하고 출력 gradient와 손실 gradient를 구분할 수 있다.
- [ ] Softmax와 cross-entropy를 쓰고 정답 클래스 확률로 NLL을 계산할 수 있다.
- [ ] Overfitting, L2, dropout이 무엇을 조절하는지 설명할 수 있다.
- [ ] 의미 유사성과 관련성을 구분하고 cosine, TF-IDF, PMI를 계산할 수 있다.
- [ ] Sparse/dense, one-hot/분포 기반 벡터, static/contextual의 차이를 설명할 수 있다.

두 번째 단계에서는 이 노트의 본문을 가리고 단원별 핵심 키워드만 보며 정의·공식·조건·예시를 직접 적는다. 세 번째 단계에서는 복기본의 7유형에 맞춰 숫자와 문장을 바꾼 모의시험을 푼다.
