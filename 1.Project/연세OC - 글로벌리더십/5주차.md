리더십에 관한 연구
- Great-man theory
- Situationalist view
- Contingency theory
- Transaction theory: Social contract
시대적 결정론(Situationalist view)
- 리더가 탄생한 시대의 사회적 정치적 환경에 집중 -> view
-  타고난 소질과 환경의 차이
- Inexplicably complex controversial calculation between the world and him -> divine mystery
- Life Cycle Theory of Leadership
	- 허시-블랜차드 모델
		- 3차원 관리 스타일 이론
		- 이끄는 사람들의 스타일과 능력에 맞춘 리더십
	- 상황적응 이론
		- 천부적 재능으로 항상 영웅이 되는 것은 아닌다
	- Social Contract Theory
		- 리더와 시민들의 계약 
		- 리더십과 지지
		- 리더십의 가치 하락=지지철회
		- 시대가 요구하는 리더십=시민이 필요하는 리더십
	- 리더십은 키워나갈 수 있고 시대가 요구하는 재능을 키우는 것이 필요
	- 정신적, 사회적 기질
		- 자기수양과 노력(심리적 안정과 집중력)
		- 어울림(네트워크 형성)
		- 다양한 정보의 획득
	- 필요의 위계
		- 물리적 생존 -> 사회적 생존 -> 자존감

상황에 따른 리더십
서로 상반되는 리더십
- Empowerment <-> Managerial leadership
- Leadership <-> Followership
- Authoritative <-> Servant Leadership
- Administrative <-> Popular Leadership
- 모든 것을 가지고 상황에 따라 사용해야함
- 조직의 피로도를 낮추기 위해서
1분 매니저

| 구분       | 의지(low) | 의지(high) |
| -------- | ------- | -------- |
| 능력(low)  | M1      | M2       |
| 능력(high) | M3      | M4       |
- 각각의 구분에 해당하는 사람에게 필요한 리더십들
- M1: 지시형 / M2: 코치형 / M3: 지원형 / M4: 위임형
- M1
	- 전통, 위계, 지위에서 오는 권위
	- 리더 자신에게서 우러나는 권위 vs 지위에서 우러나는 권위
	- 실력이 뒷받침된 권위
	- 능력과 경험 -> 실무와 관리
- M2
	- 자신이 해보지 않은 일은 시키지 않는게 중요
- M3
	- 리더는 훌륭한 일을 하는 사람이 아니라 사람들로 하여금 훌륭한 일을 하게 만드는 사람
	- 동기부여가 중요
- M4
	- 성장 기회 부여
	- 후진 양성
- M2 vs M4
	- 상황 판단에 따른 선택 (leadership = 판단력)
