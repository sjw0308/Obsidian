# 중간개념 총정리

> **범위:** 개인 정리 1–7번과 기존 과제에서 확인한 신호·시스템 기초, 에너지·평균 전력, 선형 시스템, 컨볼루션, 연속시간 푸리에 급수·변환·성질.
> **읽는 순서:** 시간이 없으면 0번과 10번 → 시스템 판정은 3–4번 → 계산 공식은 2번, 5–9번.
> 이산시간은 기초 신호·시스템·컨볼루션까지 다룬다. DTFS·DTFT·표본화 정리·라플라스 변환의 본격적인 해석은 이 요약의 범위에 넣지 않았다.

## 0. 시험 직전 한눈에 보기

| 주제 | 반드시 기억할 것 | 자주 하는 실수 |
|---|---|---|
| 신호 구분 | 연속시간은 x(t), 이산시간은 x[n] | 이산시간이라고 진폭까지 이산적인 것은 아님 |
| 주기성 | CT: 양의 실수 T, DT: 양의 정수 N으로 반복 | DT 정현파가 항상 주기적이라고 판단 |
| 에너지·전력 | 에너지에는 절댓값 제곱, 전력에는 시간 평균 | 복소신호에 x² 사용, 한쪽 신호의 양측 평균 혼동 |
| 선형성 | 가산성과 동차성이 모두 성립 | 영입력 출력이 0이라는 것만으로 선형 판정 |
| 시불변성 | 이동한 입력의 출력 = 원 출력의 이동 | 선형이면 시불변이라고 판단 |
| 무기억 | 현재 입력 값만으로 현재 출력 결정 | 미래만 사용하는 시스템을 무기억이라고 판단 |
| 인과성 | 미래 입력을 사용하지 않음 | 기억이 있으면 무조건 비인과적이라고 판단 |
| 안정성 | 모든 유계 입력 → 유계 출력 | 출력이 하나라도 유계이면 안정하다고 판단 |
| 컨볼루션 | 반전·이동 후 겹치는 구간에서 적분·합 | 이동량, 구간, 더미 인덱스 혼동 |
| LTI | y=x*h, 시스템 특성은 h로 판단 | 일반 선형 시변 시스템에도 같은 식 사용 |
| 푸리에 급수 | 주기신호, 계수에 1/T | 기본주파수·고조파 인덱스 혼동 |
| 푸리에 변환 | 역변환에 1/(2π) | 주기신호의 임펄스 가중치에서 2π 누락 |
| 시간·주파수 이동 | 시간 이동 → 위상, 복소지수 곱 → 주파수 이동 | 두 성질을 서로 바꾸어 사용 |
| 컨볼루션·곱 | 시간 컨볼루션 → 주파수 곱 | 시간 곱의 주파수 컨볼루션에서 1/(2π) 누락 |

전체 흐름은 **신호를 임펄스로 분해 → LTI 응답은 컨볼루션 → 복소지수는 LTI의 고유함수 → 신호를 주파수 성분으로 분해하여 각 성분에 H를 곱함**이다.

## 1. 기본 신호와 시간축 변환

### 1.1 연속시간·이산시간

- 연속시간 신호 x(t): 실수 시간 t에서 정의.
- 이산시간 신호 x\[n]: 정수 인덱스 n에서 정의. 진폭은 실수·복소수 모두 가능.
- 표본 간격이 T_s이면 $x[n]=x_c(nT_s)$.
- **시간축을 이산화하는 표본화와 진폭을 이산화하는 양자화는 별개**이다.

### 1.2 복소수·지수·정현파

$$e^{j\theta}=\cos\theta+j\sin\theta,\qquad |z|^2=zz^*.$$

$$\cos\theta=\frac{e^{j\theta}+e^{-j\theta}}2,\qquad \sin\theta=\frac{e^{j\theta}-e^{-j\theta}}{2j}.$$

$$Ce^{(\sigma+j\omega)t}=Ce^{\sigma t}e^{j\omega t}.$$

실수부 σ는 진폭 포락선의 증가·감소를, 허수부 ω는 진동을 결정한다. $|e^{j\theta}|=1$이며, 진동 성분이 있어도 포락선이 변하면 전체 신호는 일반적으로 주기적이지 않다.

### 1.3 주기성과 기본주기

**연속시간:** 모든 t에서 $x(t+T)=x(t)$인 T>0가 있으면 주기적이다. 최소 양의 주기가 존재하면 기본주기 T₀이고 $\omega_0=2\pi/T_0$이다.

정현파·복소지수의 주파수 ω≠0일 때 $T_0=2\pi/|\omega|$. 여러 정현파의 합은 주파수들이 공통 기본주파수의 정수배인지 확인한다. 실제로 남아 있는 성분을 기준으로 최소 주기를 찾는다.

**이산시간:** 모든 n에서 $x[n+N]=x[n]$인 **양의 정수 N**이 필요하다.

$$e^{j\omega_0 n}\text{의 주기 조건:}\quad \omega_0N=2\pi m\quad(m\in\mathbb Z).$$

따라서 $\omega_0/(2\pi)$가 유리수여야 한다. 또한 $e^{j(\omega+2\pi m)n}=e^{j\omega n}$이다.

- $\cos(\pi n/2)$: 기본주기 4.
- $e^{jn}$: 비주기.
- 상수 연속시간 신호는 모든 T>0가 주기라 최소 양의 기본주기가 없다.

### 1.4 짝·홀 분해

$$x_e(t)=\frac{x(t)+x(-t)}2,\qquad x_o(t)=\frac{x(t)-x(-t)}2,\qquad x=x_e+x_o.$$

- 짝함수: $x(-t)=x(t)$.
- 홀함수: $x(-t)=-x(t)$.
- 짝×짝, 홀×홀은 짝; 짝×홀은 홀.
- 대칭 구간에서 적분 가능한 홀함수의 적분은 0. 짝함수의 적분은 양의 절반 구간 적분의 두 배.
- 같은 식을 이산시간 n에도 적용할 수 있다.

### 1.5 시간 이동·반전·스케일링

| 신호                  | 의미              |     |        |
| ------------------- | --------------- | --- | ------ |
| $x(t-t_0)$, $t_0>0$ | 오른쪽으로 t₀ 이동, 지연 |     |        |
| $x(t+t_0)$          | 왼쪽으로 t₀ 이동, 앞당김 |     |        |
| $x(-t)$             | 시간 반전           |     |        |
| $x(at)$, $          | a               | >1$ | 시간축 압축 |
| $x(at)$, $0<        | a               | <1$ | 시간축 확장 |

**안전한 구간 계산:** 원 신호가 $L\le t\le R$에서 비영이면 $x(at+b)$에는 $L\le at+b\le R$을 적용한다. a<0이면 부등호 방향에 주의한다.

예: x가 \[0,2]에서 비영이면 $x(2t-2)$는 \[1,2]에서 비영이다. $x(at+b)=x(a(t+b/a))$를 이용할 수도 있지만, 구간 부등식으로 확인하면 이동 순서 실수를 줄일 수 있다.

### 1.6 계단과 임펄스

$$u[n]=\begin{cases}1,&n\ge0,\\0,&n<0,\end{cases}\qquad \delta[n]=\begin{cases}1,&n=0,\\0,&n\ne0.\end{cases}$$

$$\delta[n]=u[n]-u[n-1],\qquad u[n]=\sum_{k=-\infty}^{n}\delta[k].$$

연속시간 임펄스는 보통 함수의 한 점에서의 무한대 값으로 계산하는 대상이 아니다. **단위 면적과 추출 성질을 갖는 일반화된 신호**로 다룬다.

$$\int_{-\infty}^{\infty}\delta(t)dt=1,\qquad \int_{-\infty}^{\infty}f(t)\delta(t-t_0)dt=f(t_0).$$

위 추출식은 f가 해당 점에서 연속일 때 사용한다.

$$\frac{du(t)}{dt}=\delta(t),\qquad u(t)=\int_{-\infty}^{t}\delta(\tau)d\tau.$$

$$\delta(at)=\frac1{|a|}\delta(t),\qquad \delta(at+b)=\frac1{|a|}\delta\left(t+\frac ba\right),\quad a\ne0.$$

사각 펄스는 $u(t-a)-u(t-b)$로 표현한다(a<b). 이산시간의 $u[n]-u[n-M]$은 n=0부터 M−1까지 **M개 표본**이 1이다.

## 2. 에너지와 평균 전력

### 2.1 정의

$$E_x=\int_{-\infty}^{\infty}|x(t)|^2dt,\qquad E_x=\sum_{n=-\infty}^{\infty}|x[n]|^2.$$

$$P_x=\lim_{T\to\infty}\frac1{2T}\int_{-T}^{T}|x(t)|^2dt,$$
$$P_x=\lim_{N\to\infty}\frac1{2N+1}\sum_{n=-N}^{N}|x[n]|^2.$$

평균 전력은 **크기 제곱의 시간 평균**이다. 신호 자체의 평균값과 다르다. 복소신호는 $x^2$가 아니라 $|x|^2$을 사용한다.

| 분류 | 조건 | 결과 |
|---|---|---|
| 에너지 신호 | $0<E_x<\infty$ | $P_x=0$ |
| 전력 신호 | $0<P_x<\infty$ | $E_x=\infty$ |
| 그 밖 | 예: 전력도 발산하거나 평균 극한이 없음 | 위 두 분류에 속하지 않을 수 있음 |

**‘유한한 평균 전력 → 무한 에너지’는 P=0까지 포함하면 거짓이다.** 양의 유한 전력이어야 한다. 영신호는 위의 엄격한 정의에서 둘 다 아니다.

### 2.2 주기신호의 전력

$$P_x=\frac1{T_0}\int_{t_0}^{t_0+T_0}|x(t)|^2dt,\qquad P_x=\frac1{N_0}\sum_{n=n_0}^{n_0+N_0-1}|x[n]|^2.$$

연속시간에서 ω≠0일 때:

$$x(t)=Ae^{j(\omega t+\phi)}\Rightarrow P_x=|A|^2,$$
$$x(t)=A\cos(\omega t+\phi)\Rightarrow P_x=\frac{|A|^2}{2}.$$

이산 정현파에는 퇴화하는 주파수(예: ω=0, π)가 있으므로 무조건 $A^2/2$를 적용하지 말고 한 주기 표본을 확인한다.

상수 C의 전력은 $|C|^2$. 양측 평균 정의에서 $u(t)$와 $u[n]$의 전력은 1/2이다.

### 2.3 자주 쓰는 에너지·스케일링

$$x(t)=Ae^{-at}u(t),\quad a>0\quad\Rightarrow\quad E_x=\frac{|A|^2}{2a},\ P_x=0.$$

$$x[n]=A\alpha^nu[n],\quad |\alpha|<1\quad\Rightarrow\quad E_x=\frac{|A|^2}{1-|\alpha|^2},\ P_x=0.$$

$$y(t)=Ax(at+b)\quad\Rightarrow\quad E_y=\frac{|A|^2}{|a|}E_x,\quad a\ne0.$$

시간 이동·반전은 에너지를 바꾸지 않는다. 시간축 압축은 연속시간 에너지를 줄인다. 이 식을 이산시간의 다운샘플링에 그대로 적용하면 안 된다.

**합의 전력:** 일반적으로 $P_{x+y}\ne P_x+P_y$. 제곱을 전개했을 때 교차항의 시간 평균이 0인 경우에만 더할 수 있다.

## 3. 시스템의 성질 판정

시스템을 $\mathcal S$로 표기한다. 각 성질은 **모든 허용 입력**에 대해 성립해야 한다. 거짓임을 보일 때는 반례 하나로 충분하다.

### 3.1 선형성

$$\mathcal S\{ax_1+bx_2\}=a\mathcal S\{x_1\}+b\mathcal S\{x_2\}.$$

가산성과 동차성을 모두 만족해야 한다. 영입력에서 영출력이 나오는 것은 필요조건일 뿐 충분조건은 아니다.

- $y=tx(t)$, $y=\cos t\,x(t)$: 선형.
- $y=x^2(t)$, $y=|x(t)|$, $y=x(t)+1$: 비선형.
- 미분·적분·지연 연산은 적절한 정의역에서 선형. 고정된 비영 초기조건이 더해지는 전체 입출력 관계는 별도 확인.

### 3.2 시불변성

원 입력 x의 출력이 y일 때, 모든 이동량 t₀에 대해

$$\mathcal S\{x(t-t_0)\}=y(t-t_0).$$

**판정 순서:** ① 입력만 이동해 시스템에 넣음 → ② 원 출력 전체를 이동 → ③ 두 식 비교.

- $y=x(t-2)$: 시불변.
- $y=tx(t)$: 시변. 두 식은 $t x(t-t_0)$와 $(t-t_0)x(t-t_0)$.
- $y=x(2t)$: 시변. 두 식은 $x(2t-t_0)$와 $x(2t-2t_0)$.

### 3.3 기억 유무

무기억이면 현재 출력 y(t₀)가 **같은 시각의 입력 값 x(t₀)만**으로 결정된다.

- $y=x^2(t)$, $y=tx(t)$: 무기억.
- 지연·앞당김·누적 적분·미분: 기억이 있음.
- 미래 입력만 참조해도 무기억이 아니다.

### 3.4 인과성

현재 출력은 현재·과거 입력에만 의존해야 한다.

- $y=x(t)+x(t-1)$: 인과적.
- $y=x(t+1)$: 비인과적.
- $y=x(-t)$: 음의 t에서 미래 입력을 참조하므로 시스템 전체로는 비인과적.
- $y=\int_{-\infty}^t x(\tau)d\tau$: 인과적이지만 기억이 있음.

### 3.5 BIBO 안정성

$$|x(t)|\le M_x<\infty\ \text{for all }t\quad\Rightarrow\quad |y(t)|\le M_y<\infty\ \text{for all }t.$$

- $y=\sin t\,x(t)$: 안정, $|y|\le M_x$.
- $y=tx(t)$: 불안정, 입력 x=1이 반례.
- $y=x^2(t)$: 안정, $|y|\le M_x^2$. 비선형과 불안정은 다른 성질이다.
- 미분기: 불안정. 유계 입력 $x(t)=\sin(t^2)$의 도함수 $2t\cos(t^2)$는 비유계.
- 누적 적분기: 불안정. 입력 u(t)에 대해 출력 t u(t).

### 3.6 가역성과 역시스템

서로 다른 입력이 같은 출력을 만들지 않아야 한다. 역시스템은 출력을 받아 원 입력을 복원한다.

- $y=3x(t-1)$: 가역, $x(t)=y(t+1)/3$.
- $y=x^2(t)$: 실수 입력 전체에서는 비가역. x와 −x를 구분하지 못함.
- $y=dx/dt$: 상수 차이를 잃으므로 입력 제한·추가 정보 없이는 비가역.
- 가역 시스템의 역이 반드시 인과적이거나 안정한 것은 아니다.

### 3.7 선형화

미분 가능한 정적 관계 $y=f(x)$에서 작동점을 $(x^*,y^*)$, $y^*=f(x^*)$로 잡으면

$$x=x^*+\epsilon_x,\quad y=y^*+\epsilon_y,\qquad \epsilon_y\approx f'(x^*)\epsilon_x.$$

작동점은 작은 변화 자체가 아니다. **작은 것은 편차 ε**이며, 선형화는 고차항을 무시한 국소 근사다. 원래 시스템이 전역적으로 선형이라는 뜻이 아니다.

## 4. LTI와 임펄스 응답

### 4.1 왜 컨볼루션으로 표현되는가?

이산시간 신호를 이동 임펄스들의 합으로 표현한다.

$$x[n]=\sum_{k=-\infty}^{\infty}x[k]\delta[n-k].$$

선형성이면 각 입력에 대한 응답을 가중합할 수 있다. 시불변성이면 δ\[n−k]의 응답은 h\[n−k]이다. 따라서

$$y[n]=\sum_k x[k]h[n-k]=x[n]*h[n].$$

연속시간도 마찬가지로

$$x(t)=\int_{-\infty}^{\infty}x(\tau)\delta(t-\tau)d\tau,\qquad y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)d\tau.$$

일반적인 선형 **시변** 시스템은 이동 임펄스마다 응답이 다르므로 하나의 h만으로 위 컨볼루션을 쓸 수 없다.

### 4.2 h로 판정하는 LTI 성질

| 성질                    | 연속시간              | 이산시간              |            |         |      |          |
| --------------------- | ----------------- | ----------------- | ---------- | ------- | ---- | -------- |
| 인과성                   | t<0에서 h(t)=0      | n<0에서 h\[n]=0     |            |         |      |          |
| BIBO 안정성: 보통 함수·수열인 h | $\int             | h(t)              | dt<\infty$ | $\sum_n | h[n] | <\infty$ |
| 무기억                   | $h(t)=K\delta(t)$ | $h[n]=K\delta[n]$ |            |         |      |          |
| LTI 역시스템 g            | $h*g=\delta(t)$   | $h*g=\delta[n]$   |            |         |      |          |

CT에서 h에 임펄스가 포함되면 보통 함수의 절댓값 적분을 형식적으로 계산하지 않는다. 유한 가중 임펄스는 유한 이득의 지연 연산이므로, 보통 함수 부분의 절대적분과 함께 입출력 유계성을 판단한다.

**인과성과 안정성은 독립적이다.** $e^tu(t)$는 인과적이지만 불안정하고, $e^tu(-t)$는 비인과적이지만 안정하다.

### 4.3 계단응답과 1차 응답

계단응답 s는 $s=h*u$이다.

$$s(t)=\int_{-\infty}^{t}h(\tau)d\tau,\qquad h(t)=\frac{ds(t)}{dt},$$
$$s[n]=\sum_{k=-\infty}^{n}h[k],\qquad h[n]=s[n]-s[n-1].$$

예를 들어 $h(t)=e^{-at}u(t)$, a>0이면 $s(t)=(1-e^{-at})u(t)/a$. 정규화된 1차 시스템 $h(t)=ae^{-at}u(t)$의 계단응답은 $(1-e^{-at})u(t)$이다. **최종값의 1/a 유무는 h의 계수에 달려 있다.**

## 5. 컨볼루션 계산

### 5.1 정의와 성질

$$y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)d\tau,\qquad y[n]=\sum_{k=-\infty}^{\infty}x[k]h[n-k].$$

- 교환: $x*h=h*x$.
- 분배: $x*(h_1+h_2)=x*h_1+x*h_2$.
- 결합: $(x*h_1)*h_2=x*(h_1*h_2)$ → 직렬 LTI의 전체 응답은 h들의 컨볼루션.
- $x*\delta=x$, $x*\delta(t-t_0)=x(t-t_0)$.
- $x(t-a)*h(t-b)=(x*h)(t-a-b)$: **두 이동량은 더해진다.**
- $x(-t)*h(-t)=(x*h)(-t)$.

### 5.2 겹치는 구간부터 찾기

x가 \[a,b], h가 \[c,d] 밖에서 0이면, 적분 변수 τ의 조건은

$$a\le\tau\le b,\qquad c\le t-\tau\le d.$$

따라서

$$\max(a,t-d)\le\tau\le\min(b,t-c).$$

하한이 상한보다 크면 출력은 0. 출력은 \[a+c,b+d] 밖에서 0이지만, 그 안에서도 상쇄로 0이 될 수 있다. 이산시간도 같은 방식으로 정수 k의 범위를 찾는다.

### 5.3 대표 결과

**이산 지수와 계단**

$$\alpha^nu[n]*u[n]=\left(\sum_{k=0}^{n}\alpha^k\right)u[n]=\frac{1-\alpha^{n+1}}{1-\alpha}u[n],\quad \alpha\ne1.$$

α=1이면 $(n+1)u[n]$. 합 안의 지수는 **αᵏ**이지 αⁿ이 아니다.

**인과적 연속 지수 두 개**

$$e^{-at}u(t)*e^{-bt}u(t)=\begin{cases}
\dfrac{e^{-at}-e^{-bt}}{b-a}u(t),&a\ne b,\\
te^{-at}u(t),&a=b.
\end{cases}$$

적분 구간은 0≤τ≤t. 동일 지수율에서는 분모가 0인 식을 그대로 쓰지 말고 직접 적분하거나 극한을 취한다.

**사각 펄스 두 개**는 겹치는 길이로 계산한다. 같은 폭·높이의 펄스끼리는 삼각형이 된다. 예: p(t)=1 for |t|<1이면 $(p*p)(t)=2-|t|$ for |t|<2, 그 밖에서는 0.

**계산 후 확인:** 시작·끝 시각, 경계 연속성, 대표 표본, 양수 신호끼리의 컨볼루션이 음수가 되지 않는지 확인한다. 점프의 미분에는 임펄스가 생기지만, 연속 삼각형의 첫 미분에는 임펄스가 없다.

## 6. 복소지수 고유함수와 푸리에 급수

### 6.1 LTI가 복소지수를 다루는 방식

$$x(t)=e^{st}\Rightarrow y(t)=\int h(\tau)e^{s(t-\tau)}d\tau=e^{st}\underbrace{\int h(\tau)e^{-s\tau}d\tau}_{H(s)}.$$

적분이 수렴하면 eˢᵗ는 고유함수, H(s)는 고유값이다. 특히 s=jω이면 **주파수는 그대로이고 크기·위상만 H(jω)에 따라 변한다.** 유도 중 지수는 $e^{-s\tau}$이며 $e^{-st}$가 아니다.

### 6.2 연속시간 푸리에 급수: 주기신호의 분해

$$\omega_0=\frac{2\pi}{T},\qquad x(t)=\sum_{k=-\infty}^{\infty}a_ke^{jk\omega_0t},$$
$$\boxed{a_k=\frac1T\int_{t_0}^{t_0+T}x(t)e^{-jk\omega_0t}dt.}$$

- 적분 구간은 **어디서 시작하든 연속된 한 주기**면 된다.
- k=0은 DC, k=±1은 기본주파수 성분, k=±m은 m차 고조파.
- $a_0$는 신호의 주기 평균.
- 계수식은 서로 다른 복소지수의 직교성에서 나온다.

$$\frac1T\int_{t_0}^{t_0+T}e^{j(k-m)\omega_0t}dt=\begin{cases}1,&k=m,\\0,&k\ne m.\end{cases}$$

### 6.3 삼각함수에서 계수 읽기

$$A\cos(m\omega_0t+\phi)\Rightarrow a_m=\frac A2e^{j\phi},\ a_{-m}=\frac A2e^{-j\phi},$$
$$A\sin(m\omega_0t+\phi)\Rightarrow a_m=\frac A{2j}e^{j\phi},\ a_{-m}=-\frac A{2j}e^{-j\phi},\quad m>0.$$

사인 양의 주파수 계수의 $1/j=-j$ 부호에 주의한다. 여러 주파수가 있으면 공통 ω₀를 정한 뒤 각 주파수를 **kω₀**에 대응시킨다.

### 6.4 대칭·수렴·대표 파형

- 실수 x: $a_{-k}=a_k^*$.
- 짝 x: $a_{-k}=a_k$.
- 실수·짝 x: 계수는 실수·짝 대칭.
- 실수·홀 x: 계수는 순허수·홀 대칭이고 $a_0=0$.
- 시간 이동: $x(t-t_0)$의 계수는 $a_ke^{-jk\omega_0t_0}$.

주기 T에서 x(t)=A for |t|<τ, 나머지는 0인 펄스열(0<τ<T/2):

$$a_0=\frac{2A\tau}{T},\qquad a_k=\frac{A\sin(k\omega_0\tau)}{k\pi},\quad k\ne0.$$

**Dirichlet 충분조건:** 한 주기에서 절대적분 가능, 한 주기 내 극값·불연속점이 유한 개이며 불연속점의 좌우 극한이 유한한 등의 조건 아래, 연속점에서는 함수값으로, 점프점에서는 $[x(t^-)+x(t^+)]/2$로 급수가 수렴한다.

이 조건을 만족하지 않는다고 모든 의미의 푸리에 표현이 불가능한 것은 아니다. 임펄스열은 일반화된 의미로 다룬다. 점프점에 따로 지정한 함수값은 급수 계수를 바꾸지 않는다.

### 6.5 주기입력의 LTI 출력

$$x(t)=\sum_ka_ke^{jk\omega_0t}\quad\Rightarrow\quad y(t)=\sum_kb_ke^{jk\omega_0t},\qquad \boxed{b_k=H(jk\omega_0)a_k.}$$

입력이 $A\cos(\omega t+\phi)$이면 출력은

$$A|H(j\omega)|\cos\big(\omega t+\phi+\arg H(j\omega)\big)$$

이다(실수 임펄스 응답의 LTI, 응답이 존재하는 경우). DC도 H(0)를 곱한다. 켜지는 입력에 u(t)가 붙으면 별도의 과도응답을 고려해야 하므로, 전 시간축 정현파 입력과 혼동하지 않는다.

## 7. 연속시간 푸리에 변환

### 7.1 정의와 푸리에 급수와의 연결

$$\boxed{X(j\omega)=\int_{-\infty}^{\infty}x(t)e^{-j\omega t}dt,}$$
$$\boxed{x(t)=\frac1{2\pi}\int_{-\infty}^{\infty}X(j\omega)e^{j\omega t}d\omega.}$$

- 시간영역 x(t)를 연속 주파수 변수 ω의 표현으로 바꾼다.
- 비주기 신호를 긴 주기로 반복한 뒤 T→∞로 보내면 주파수 간격 $\Delta\omega=2\pi/T$가 0으로 간다.
- 단순히 X≈aₖ가 아니다. 한 주기 파형 x₀를 반복하고 그 변환을 X₀라 하면 **$a_k=X_0(jk\omega_0)/T$**이다.
- 보통의 적분으로 변환이 존재하는 충분조건은 $\int|x(t)|dt<\infty$. 역변환의 점별 수렴에는 조각별 매끄러움 등의 조건도 함께 고려한다.
- 상수·정현파·계단은 절대적분 가능하지 않지만 임펄스·주값을 사용하는 일반화된 변환으로 다룰 수 있다.

### 7.2 기본 변환쌍

아래 a>0, T₁>0이다. 식의 ω=0 특이점이 제거 가능하면 극한값을 쓴다.

| 시간영역              | 주파수영역                                                         |                |                            |
| ----------------- | ------------------------------------------------------------- | -------------- | -------------------------- |
| $\delta(t)$       | $1$                                                           |                |                            |
| $\delta(t-t_0)$   | $e^{-j\omega t_0}$                                            |                |                            |
| $1$               | $2\pi\delta(\omega)$                                          |                |                            |
| $e^{j\omega_ct}$  | $2\pi\delta(\omega-\omega_c)$                                 |                |                            |
| $\cos(\omega_ct)$ | $\pi[\delta(\omega-\omega_c)+\delta(\omega+\omega_c)]$        |                |                            |
| $\sin(\omega_ct)$ | $\frac\pi j[\delta(\omega-\omega_c)-\delta(\omega+\omega_c)]$ |                |                            |
| $e^{-at}u(t)$     | $1/(a+j\omega)$                                               |                |                            |
| $e^{-a            | t                                                             | }$             | $2a/(a^2+\omega^2)$        |
| $p(t)=1$ for $    | t                                                             | <T_1$, 그 밖에서 0 | $2\sin(\omega T_1)/\omega$ |
| $u(t)$            | $\operatorname{PV}(1/(j\omega))+\pi\delta(\omega)$            |                |                            |

사각 펄스의 ω=0 값은 2T₁이며, 높이가 A면 전체 변환에 A를 곱한다. PV는 특이점을 주값의 의미로 해석한다는 표시다.

### 7.3 주기신호의 변환

$$x(t)=\sum_ka_ke^{jk\omega_0t}\quad\Longleftrightarrow\quad \boxed{X(j\omega)=2\pi\sum_ka_k\delta(\omega-k\omega_0).}$$

연속시간 주기신호의 스펙트럼은 이산적인 위치에 있는 임펄스들의 모음이다. **이산적인 선 스펙트럼이라는 말과 이산시간 신호라는 말은 다르다.** 임펄스의 가중치는 높이 대신 면적으로 해석한다.

## 8. 푸리에 변환의 성질

이 절에서는 $x(t)\leftrightarrow X(j\omega)$, $y(t)\leftrightarrow Y(j\omega)$로 둔다. 일부 성질은 과제에서 사용한 내용을 복습하기 위한 보충이다.

### 8.1 핵심 성질표

| 시간영역                 | 주파수영역                                |
| -------------------- | ------------------------------------ |
| $ax(t)+by(t)$        | $aX(j\omega)+bY(j\omega)$            |
| $x(t-t_0)$           | $e^{-j\omega t_0}X(j\omega)$         |
| $e^{j\omega_ct}x(t)$ | $X(j(\omega-\omega_c))$              |
| $x(-t)$              | $X(-j\omega)$                        |
| $x(at)$, a≠0         | $\frac1{a}X(j\omega/a)$              |
| $x^*(t)$             | $X^*(-j\omega)$                      |
| $d^m x(t)/dt^m$      | $(j\omega)^mX(j\omega)$              |
| $t x(t)$             | $j\,dX(j\omega)/d\omega$             |
| $x*y$                | $XY$                                 |
| $xy$                 | $\frac1{2\pi}(X*Y)$(주파수 변수에 대한 컨볼루션) |

**합성 시간축 변환**

$$x(at+b)\longleftrightarrow\frac1{|a|}e^{j\omega b/a}X(j\omega/a).$$

예: $x(3t-6)\leftrightarrow\frac13 e^{-j2\omega}X(j\omega/3)$.

예: $x(1-t)\leftrightarrow e^{-j\omega}X(-j\omega)$.

시간 이동은 스펙트럼의 크기를 바꾸지 않고 선형 위상을 더한다. 시간 압축은 스펙트럼을 넓히면서 크기에 1/|a|를 곱한다.

### 8.2 적분 성질과 단위 계단

$$z(t)=\int_{-\infty}^{t}x(\tau)d\tau=x*u$$
이면, 보통의 함수 X로 해당 곱을 정의할 수 있는 조건에서

$$Z(j\omega)=\operatorname{PV}\left(\frac{X(j\omega)}{j\omega}\right)+\pi X(j0)\delta(\omega).$$

이는 일반화된 변환식이며 1/ω 항은 주값으로 해석한다. **적분했다고 단순히 X/(jω)만 쓰면 DC 임펄스를 놓칠 수 있다.**

예: x=δ이면 X=1이고, 적분 결과 u(t)의 변환은 $\operatorname{PV}(1/(j\omega))+\pi\delta(\omega)$이다. 반대로 미분 성질만으로 u의 변환을 구하면 ω=0의 임펄스 성분을 결정하지 못한다.

### 8.3 변조: 코사인·사인 곱

$$x(t)\cos(\omega_ct)\longleftrightarrow\frac12\left[X(j(\omega-\omega_c))+X(j(\omega+\omega_c))\right],$$
$$x(t)\sin(\omega_ct)\longleftrightarrow\frac1{2j}\left[X(j(\omega-\omega_c))-X(j(\omega+\omega_c))\right].$$

중심 주파수 양쪽으로 스펙트럼 복사본이 이동한다. 사인은 두 복사본의 차와 1/(2j)에 주의한다.

### 8.4 대칭으로 원 신호의 성질 판정

| 시간영역 x(t)의 성질 | 주파수영역 X(jω)의 성질 |
|---|---|
| 실수 | 켤레대칭: $X(-j\omega)=X^*(j\omega)$ |
| 순허수 | 켤레반대칭: $X(-j\omega)=-X^*(j\omega)$ |
| 짝 | 짝 |
| 홀 | 홀 |
| 실수·짝 | 실수·짝 |
| 실수·홀 | 순허수·홀 |
| 순허수·짝 | 순허수·짝 |
| 순허수·홀 | 실수·홀 |

**실수 신호라고 X까지 실수인 것은 아니다.** 실수 x의 경우 Re X는 짝, Im X는 홀이다. 위 대응은 역으로도 이용할 수 있다(변환·역변환이 성립하는 범위에서).

예: X가 실수·홀 함수라면 x는 순허수·홀 함수다. X가 양의 주파수에만 존재하고 켤레대칭이 아니면 원 신호를 실수라고 판정할 수 없다.

### 8.5 추가로 유용한 확인식

적분과 값이 잘 정의되는 경우:

$$X(j0)=\int_{-\infty}^{\infty}x(t)dt,\qquad x(0)=\frac1{2\pi}\int_{-\infty}^{\infty}X(j\omega)d\omega.$$

유한 에너지 신호의 Parseval 관계는

$$E_x=\int|x(t)|^2dt=\frac1{2\pi}\int|X(j\omega)|^2d\omega.$$

연속시간 주기신호의 푸리에 급수에 대한 관계는 $P_x=\sum_k|a_k|^2$이다. 에너지 적분과 주기신호의 전력을 구분한다.

## 9. 계산 유형별 접근 순서

### 에너지·전력

1. 계단·구간 조건으로 비영 구간을 찾는다.
2. |x|²를 정확히 만든다. 복소지수의 위상은 절댓값에서 사라진다.
3. 유한 에너지면 전력은 0. 주기신호면 한 주기 평균을 쓴다.
4. 전력 합산 전에 교차항 평균이 0인지 확인한다.

### 시스템 성질

선형성 → 시불변성 → 기억 → 인과성 → 안정성을 **각각 따로** 판정한다. 시불변성은 두 경로의 식을 쓰고, 불안정성은 유계 입력 반례를 제시한다. LTI가 확인되면 h로 판정할 수 있다.

### 컨볼루션

1. 임펄스 합이나 계단 차로 분해할 수 있는지 본다.
2. 적분·합 변수에 대해 두 신호가 동시에 비영인 구간을 구한다.
3. 구간 경계가 바뀌는 t 또는 n에서 경우를 나눈다.
4. 각 구간 식을 계산하고 스케치·연속성·끝 동작을 확인한다.

### 푸리에 급수

1. 실제 기본주기와 ω₀를 정한다.
2. 삼각함수 합이면 복소지수로 전개한다.
3. 그래프 파형이면 편한 한 주기를 골라 구간별 적분한다.
4. a₀는 별도 계산한다. k≠0 식의 k=0에 무조건 대입하지 않는다.
5. 실수성·짝홀 대칭으로 계수를 확인한다.
6. LTI 출력은 $b_k=H(jk\omega_0)a_k$.

### 푸리에 변환

1. 기본 변환쌍에 맞는 기준 신호를 찾는다.
2. 이동·반전·스케일링·미분·변조를 구분한다.
3. 시간 컨볼루션인지 시간 곱인지 확인한다.
4. 구간 제한된 정현파는 무한 정현파와 다르다. 창 함수의 곱 또는 직접 적분으로 처리한다.
5. ω=0 극한, 켤레대칭, 단위 면적·계수를 확인한다.

등비 가중 임펄스열도 과제 유형이다. T>0, |a|<1이면

$$x(t)=\sum_{k=0}^{\infty}a^k\delta(t-kT)\quad\Rightarrow\quad X(j\omega)=\sum_{k=0}^{\infty}(ae^{-j\omega T})^k=\frac1{1-ae^{-j\omega T}}.$$

**이 신호는 가중치가 변하므로 일반적으로 시간 주기신호가 아니다.** 임펄스가 일정 간격으로 놓였다는 이유만으로 주기신호의 급수 공식을 적용하지 않는다.

## 10. 마지막으로 헷갈릴 부분 점검

- 이산시간 ≠ 진폭 양자화.
- DT 주기는 양의 정수이고, CT 주기는 양의 실수다.
- 짝·홀 대칭과 실수·순허수는 별개의 분류다.
- δ(t)는 한 점의 값이 아니라 면적·추출 성질로 계산한다.
- 에너지 적분에는 |x|². 평균 전력에는 전체 관측 길이로 나누는 과정이 필요하다.
- 유한 에너지 → 전력 0. ‘유한 전력 → 무한 에너지’에는 P>0 조건이 필요하다.
- 선형성·시불변성·인과성·안정성은 서로 다른 조건이다.
- 무기억은 현재 값만 사용. 과거뿐 아니라 미래를 써도 기억이 있다.
- 인과적이어도 불안정할 수 있다. 비인과적이어도 안정할 수 있다.
- 선형화는 편차에 대한 근사다. 원 시스템의 전역 선형성과 다르다.
- 컨볼루션에서 입력 두 개의 이동량은 합쳐진다.
- 임펄스 응답 하나로 모든 출력을 결정하는 컨볼루션 표현에는 LTI가 필요하다.
- 푸리에 급수 계수에 1/T, 역푸리에 변환에 1/(2π), 주기신호의 변환에 2π.
- 시간 스케일링은 1/|a|. 음수 a의 절댓값을 빼먹지 않는다.
- 시간 이동은 위상 변화, 복소지수 곱은 주파수 이동.
- 미분은 jω를 곱함. 적분은 1/(jω) 외에 DC 임펄스가 필요할 수 있음.
- 시간 컨볼루션 → 주파수 곱. 시간 곱 → 주파수 컨볼루션과 1/(2π).
- 실수 신호의 변환은 켤레대칭이며 반드시 실수인 것은 아니다.
- 점프점에서 푸리에 급수는 좌우 극한 평균으로 수렴한다.
- Dirichlet 조건은 충분조건이다. 일반화된 변환까지 배제하는 필요조건으로 외우지 않는다.
