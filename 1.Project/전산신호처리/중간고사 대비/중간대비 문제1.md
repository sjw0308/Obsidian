# 중간대비 문제 1

범위: 신호·시스템 기초, LTI와 컨볼루션, 연속시간 푸리에 급수 및 푸리에 변환.

- T/F 44문항(22개 개념별 2문항), 계산 8문항.
- T/F는 판단과 함께 근거를 쓰고, 거짓이면 올바른 명제 또는 반례를 제시하시오.
- 계산 문제는 식의 유도 과정, 구간, 수렴 조건을 표시하시오. 스케치는 꺾이는 지점과 주요 값을 표시하시오.
- ‘평균 전력’은 무한 시간 대칭 평균을 뜻한다. 연속시간은 $P=\lim_{T\to\infty}\frac1{2T}\int_{-T}^{T}|x(t)|^2dt$, 이산시간은 $P=\lim_{N\to\infty}\frac1{2N+1}\sum_{n=-N}^{N}|x[n]|^2$이다.
- $u[n]=1$ for $n\ge0$, 나머지는 0. 연속시간 계단의 한 점 값은 적분 결과에 영향을 주지 않는다.
- 푸리에 변환은 $X(j\omega)=\int_{-\infty}^{\infty}x(t)e^{-j\omega t}dt$, 역변환은 $x(t)=\frac1{2\pi}\int_{-\infty}^{\infty}X(j\omega)e^{j\omega t}d\omega$를 사용한다.
- 각 문항은 별개이며, 원 신호는 문제에 주어진 전체 시간축에서 정의된다.

## I. 개념 및 적용 T/F

### 1. 연속시간·이산시간 신호

**TF01.** 이산시간 신호는 시간뿐 아니라 진폭도 반드시 정수 값만 가져야 한다. (T / F)

**TF02.** $x(t)=\cos(3t)$를 표본 간격 $T_s$로 표본화하면 $x[n]=\cos(3nT_s)$이다. (T / F)

### 2. 주기성과 기본주기

**TF03.** $x(t)=\cos(2t)+\sin(3t)$의 기본주기는 $2\pi$이다. (T / F)

**TF04.** $x[n]=e^{jn}$은 주기신호이다. (T / F)

### 3. 짝·홀 신호

**TF05.** 모든 신호는 짝 성분과 홀 성분의 합으로 표현할 수 있다. (T / F)

**TF06.** $x(t)=\sin t+\cos(2t)$의 짝 성분은 $\sin t$이다. (T / F)

### 4. 복소지수와 정현파

**TF07.** 실수 $\omega,\phi$에 대해 $|e^{j(\omega t+\phi)}|^2=1$이다. (T / F)

**TF08.** $x(t)=e^{(-2+j3)t}$는 주기가 $2\pi/3$인 주기신호이다. (T / F)

### 5. 단위 계단과 임펄스

**TF09.** $\int_{-\infty}^{\infty}f(t)\delta(t-2)\,dt=f(2)$이다. 단, $f$는 $t=2$에서 연속이다. (T / F)

**TF10.** 이산시간에서 $\delta[n]=u[n]-u[n+1]$이다. (T / F)

### 6. 신호 에너지와 평균 전력

**TF11.** $0<E<\infty$인 신호의 무한 시간 평균 전력은 0이다. (T / F)

**TF12.** 평균 전력이 유한하면 그 신호의 총에너지는 반드시 무한대이다. (T / F)

### 7. 시간축 변환

**TF13.** $x(t)=1$ for $0\le t\le2$, 그 밖에서는 0일 때, $x(2t-2)$는 $1\le t\le2$에서 1이다. (T / F)

**TF14.** $x(t-3)$는 원 신호를 왼쪽으로 3만큼 이동한 것이다. (T / F)

### 8. 선형성과 중첩

**TF15.** $y(t)=x(t)+2$는 선형 시스템이다. (T / F)

**TF16.** $y(t)=t\,x(t)$는 선형 시스템이다. (T / F)

### 9. 선형화

**TF17.** $y=x^2$를 $x^*=2$, $y^*=4$ 근방에서 선형화하면 $\epsilon_y\approx4\epsilon_x$이다. (T / F)

**TF18.** 작동점 근방에서 선형화할 수 있는 시스템은 원래 시스템도 모든 입력에 대해 선형이다. (T / F)

### 10. 시불변성

**TF19.** $y(t)=x(t-2)$는 시불변 시스템이다. (T / F)

**TF20.** $y(t)=\cos t\,x(t)$는 시불변 시스템이다. (T / F)

### 11. 기억 유무

**TF21.** $y(t)=x^2(t)$는 무기억 시스템이다. (T / F)

**TF22.** $y(t)=x(t+1)$는 과거 입력을 사용하지 않으므로 무기억 시스템이다. (T / F)

### 12. 인과성

**TF23.** $y[n]=x[n]+x[n-2]$는 인과적이다. (T / F)

**TF24.** $y(t)=x(-t)$는 모든 시각에서 인과적인 시스템이다. (T / F)

### 13. BIBO 안정성

**TF25.** $y(t)=\sin t\,x(t)$는 BIBO 안정하다. (T / F)

**TF26.** 이산시간 LTI 시스템의 $h[n]=u[n]$이면 BIBO 안정하다. (T / F)

### 14. 가역성과 역시스템

**TF27.** $y(t)=3x(t-1)$의 역시스템은 입력 $z(t)$에 대해 $z(t+1)/3$을 출력한다. (T / F)

**TF28.** 실수 입력에 대한 $y(t)=x^2(t)$는 가역적이다. (T / F)

### 15. 임펄스 분해와 임펄스 응답

**TF29.** 모든 이산시간 신호에 대해 $x[n]=\sum_{k=-\infty}^{\infty}x[k]\delta[n-k]$이다. (T / F)

**TF30.** 선형 시스템이면 시불변성이 없어도 단 하나의 임펄스 응답 h[n]만으로 모든 출력을 컨볼루션으로 표현할 수 있다. (T / F)

### 16. 컨볼루션의 계산과 성질

**TF31.** $y[n]=x[n]*h[n]$이면 $x[n-1]*h[n-1]=y[n-1]$이다. (T / F)

**TF32.** $x[n]=0$ for $n<2$, $h[n]=0$ for $n<3$이면 $(x*h)[n]=0$ for $n<5$이다. (T / F)

### 17. LTI의 성질과 계단응답

**TF33.** 이산시간 LTI 시스템의 계단응답이 $s[n]$이면 $h[n]=s[n]-s[n-1]$이다. (T / F)

**TF34.** 연속시간 LTI 시스템이 인과적이면 반드시 BIBO 안정하다. (T / F)

### 18. 복소지수 고유함수

**TF35.** $H(s)=\int h(\tau)e^{-s\tau}d\tau$가 수렴하면 LTI의 입력 $e^{st}$에 대한 출력은 $H(s)e^{st}$이다. (T / F)

**TF36.** LTI에 $e^{j\omega t}$를 입력하면 출력은 항상 크기와 위상이 변하지 않은 $e^{j\omega t}$이다. (T / F)

### 19. 연속시간 푸리에 급수

**TF37.** 푸리에 급수의 $a_0$는 한 주기에서 신호의 평균값이다. (T / F)

**TF38.** 기본주기 T를 사용하는 복소 푸리에 급수는 일반적으로 $a_{k+1}=a_k$인 계수열을 갖는다. (T / F)

### 20. Dirichlet 조건과 수렴

**TF39.** Dirichlet 조건을 만족하는 주기신호의 점프 불연속점에서 푸리에 급수는 좌우 극한값의 평균으로 수렴한다. (T / F)

**TF40.** $x(t)=e^{j\omega_0t}$는 전 시간축에서 절대적분 가능하지 않으므로 임펄스를 사용하는 일반화된 푸리에 변환도 존재하지 않는다. (T / F)

### 21. 푸리에 변환과 주기신호의 스펙트럼

**TF41.** $x(t)=\delta(t)$의 푸리에 변환은 모든 주파수에서 1이다. (T / F)

**TF42.** $x(t)=\sum_k a_ke^{jk\omega_0t}$의 푸리에 변환은 $\sum_k a_k\delta(\omega-k\omega_0)$이다. (T / F)

### 22. 푸리에 변환의 이동·미분·대칭 성질

**TF43.** $x(t)\leftrightarrow X(j\omega)$일 때 $x(2t-4)\leftrightarrow\frac12e^{-j2\omega}X(j\omega/2)$이다. (T / F)

**TF44.** $x(t)$가 실수이면 $X(j\omega)$는 반드시 실수이면서 짝함수이다. (T / F)

## II. 계산 문제

### 에너지·평균 전력

**C1. 연속시간 신호의 에너지와 전력**

$x(t)=e^{-2(t-1)}u(t-1)$, $y(t)=3x(2t+1)$이다.

1. 두 신호의 비영 구간과 총에너지 $E_x,E_y$를 구하시오.
2. 두 신호의 평균 전력 $P_x,P_y$를 구하고 에너지 신호인지, 전력 신호인지 분류하시오. 여기서 에너지 신호는 $0<E<\infty$, 전력 신호는 $0<P<\infty$인 신호를 뜻한다.
3. 변수 치환으로 $y(t)=Ax(at+b)$의 에너지가 $E_y=|A|^2E_x/|a|$임을 보이시오. 단, $a\ne0$이고 $E_x$는 유한하다.

**C2. 이산 주기신호의 에너지와 전력**

$$x[n]=1+2\cos\left(\frac{\pi n}{2}\right).$$

1. 기본주기와 한 주기의 표본 값을 구하시오.
2. 총에너지와 평균 전력을 구하시오.
3. $z[n]=x[n]-1$의 평균 전력을 구하시오. $P_x$에서 상수 성분의 전력을 뺄 수 있는 이유도 설명하시오.

### 컨볼루션

**C3. 이산시간 컨볼루션**

$$x[n]=\left(\frac12\right)^n u[n],\qquad h[n]=u[n]-u[n-3].$$

1. $y[n]=x[n]*h[n]$을 $n<0$, $0\le n\le2$, $n\ge3$으로 나누어 구하시오.
2. $y[0],y[1],y[2],y[3],y[4]$를 구하고 전체 출력의 형태를 스케치하시오.
3. $h[n]$을 임펄스 응답으로 갖는 LTI 시스템의 인과성과 BIBO 안정성을 판정하시오.

**C4. 연속시간 컨볼루션과 임펄스**

$$x(t)=u(t)-u(t-2),\qquad h(t)=e^{-t}u(t)+\delta(t-1).$$

1. $y(t)=x(t)*h(t)$를 $t<0$, $0\le t<1$, $1\le t<2$, $2\le t<3$, $t\ge3$으로 나누어 구하시오. 경계점의 개별 값은 요구하지 않는다.
2. 출력을 스케치하고 점프가 있는 시각과 점프 크기를 표시하시오.
3. 이 시스템의 인과성과 BIBO 안정성을 설명하시오. 임펄스 항의 입출력 작용도 고려하시오.

### 연속시간 푸리에 급수

**C5. 구간별 주기신호의 푸리에 급수**

주기 $T=4$인 신호를 한 주기에서 다음과 같이 정의한다.

$$x(t)=\begin{cases}1,&|t|<1,\\0,&1<|t|<2.\end{cases}$$

주기 연장으로 전체 신호를 정의하며, 경계점 값은 계수에 영향을 주지 않는다.

1. $\omega_0$와 모든 $a_k$를 구하시오. $k=0$을 별도로 처리하시오.
2. $a_k$가 실수이고 $a_{-k}=a_k$인 이유를 설명하시오.
3. 푸리에 급수의 $t=1$에서의 수렴값을 구하시오.

**C6. 삼각함수 입력과 LTI의 푸리에 급수 해석**

$$x(t)=2+2\cos t+4\sin(2t),\qquad h(t)=e^{-t}u(t).$$

시스템은 임펄스 응답이 $h(t)$인 LTI 시스템이며, 입력은 전 시간축에 걸쳐 주어진다.

1. 입력의 기본주파수와 0이 아닌 푸리에 계수 $a_k$를 모두 구하시오.
2. $H(j\omega)$를 구하고 출력의 푸리에 계수 $b_k$를 모두 구하시오.
3. 출력을 실수 코사인·사인의 합으로 표현하시오. 전 시간축 입력에 대한 컨볼루션 응답을 구하며, 별도의 초기조건 응답을 더하지 않는다.

### 연속시간 푸리에 변환

**C7. 양측 지수 신호와 주파수 이동**

$$x(t)=e^{-2|t|}\sin(3t).$$

1. 먼저 $g(t)=e^{-2|t|}$의 푸리에 변환을 구하시오.
2. 주파수 이동 성질을 이용해 $X(j\omega)$를 구하시오.
3. $X(j\omega)$의 실수·순허수 여부 및 짝·홀 여부를 판정하고, 시간영역 신호의 성질과 연결하시오.

**C8. 사각 펄스의 컨볼루션·이동·미분**

$$p(t)=\begin{cases}1,&|t|<1,\\0,&|t|>1,\end{cases}\qquad q(t)=(p*p)(t),\qquad r(t)=\frac{d}{dt}q(t-1).$$

경계점의 개별 값은 요구하지 않는다.

1. $P(j\omega)$를 구하고 $\omega=0$에서의 극한값을 쓰시오.
2. 컨볼루션 성질로 $Q(j\omega)$를 구하고, 시간영역의 $q(t)$를 구간별로 나타내시오.
3. 이동·미분 성질로 $R(j\omega)$를 구하고 $r(t)$를 구간별로 나타내시오. $r(t)$에 임펄스가 포함되는지도 설명하시오.
