
Convolution
- $(f*g)(t) = \int_{-\infty}^{\infty}f(\tau)g(t-\tau)d\tau$

Unit Impulse response
- 어떤 system이 x\[n]을 input으로 받아서 y\[n]을 내보낸다고 했을 때 
- $x[n]=\delta[n]$을 입력으로 넣었을 때의 output을 system의 unit impulse response, $h[n]$이라고 한다
- Unit impulse response를 보면 system의 propertie를 알 수 있다. (causality, finite or not, stableness)
Remind
- LTI system의 superposition property
	- $x[n]=\sum_{k}a_{k}x_{k}[n]=a_{1}x_{1}[n]+a_{2}x_{2}[n]+\dots$
	- $y[n]=\sum_{k}a_{k}y_{k}[n]=a_{1}y_{1}[n]+a_{2}y_{2}[n]+\dots$

Discrete Impulses & Time Shifts
- $$
  x[k]\delta[n-k]=\begin{cases}
  x[k] &n=k \\
  0 &n\neq k
  \end{cases}
  $$
- $x[n] = \sum_{k=-\infty}^{\infty}x[k]\delta[n-k]$ in general (shifting property)

Linear system을 unit impulse response로 표현하기
- $h_{k}[n]$ = $\delta[n-k]$의 impulse reponse라고 하면...
	- $y[n]=\sum_{k=-\infty}^{\infty}x[k]h_{k}[n]$으로 표현할 수 있다.
- 이때 y를 time invariant라고 가정하면(y: LTI system)
	- $h_{k}[n]=h_{0}[n-k]$이다. 이때 $h[n]=h_{0}[n]$이라고 하면
	- $y[n]=\sum_{k=-\infty}^{\infty}x[k]h[n-k]=x[n]*h[n]$ 즉, convolution sum으로 표현할 수 있다. (or superposition sum)

Example
- 문제 1
	- n = \[... -2  -1  0  1  2  3 ...]
	- x\[n] = \[... 0  0  0.5  2  0  0 ...]
	- h\[n] = \[... 0  0  1  1  1  0 ...]
	- 일 때 y를 구하기
- 1번 풀이: k를 기준으로 계산하기
	- $y[n]=\dots+x[0]h[n]+x[1]h[n-1]+\dots = 0+0.5*h[n]+2*h[n-1]+0$
	- y\[n]=\[... 0  0  0.5  2.5  2.5  2 ...]
- 2번 풀이: n을 기준으로 계산하기
	- $y[0]=\sum_{k}x[k]h[0-k] = 0.5$
	- $y[1]=\sum_{k}x[k]h[1-k] = 0.5+2$
	- $y[2]=\sum_{k}x[k]h[2-k] = 0.5+2$
	- $y[3]=\sum_{k}x[k]h[3-k] = 2$

- 문제 2
	- h\[n] = u\[n]이고 $x[n]=\alpha^n u[n]$일 때 y구하기
- 풀이
	- $y[n]=\sum_{k=-\infty}^{\infty}k[k]h[n-k] = \sum_{k=-\infty}^{\infty}\alpha^n u[k]u[n-k]$
	- 이때 $k\geq 0,\ n-k\geq 0 \to 0\leq k\leq n$에서 $u[k]u[n-k]=1$ 나머지는 0
	- For $n\geq 0$: $y[n]=\sum_{k=0}^{n}\alpha^k=\frac{1-\alpha^{n+1}}{1-\alpha}$
	- 따라서 $y[n]=()\frac{1-\alpha^{n+1}}{1-\alpha})u[n]$
