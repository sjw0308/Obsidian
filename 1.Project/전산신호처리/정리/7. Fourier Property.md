
Property
- Linearity
	- If $x(t)\stackrel{F}{\longleftrightarrow}X(j\omega)$ and $y(t)\stackrel{F}{\longleftrightarrow}Y(j\omega)$
	- then, $ax(t)+by(t)\stackrel{F}{\longleftrightarrow}aX(j\omega)+bY(j\omega)$
- Time shifting
	- If $x(t)\stackrel{F}{\longleftrightarrow}X(j\omega)$ 
	- then, $x(t-t_{0})\stackrel{F}{\longleftrightarrow}e^{-j\omega t_{0}}X(j\omega)$
- Differentiation and Integration
	- If $x(t)\stackrel{F}{\longleftrightarrow}X(j\omega)$ 
	- $\frac{d}{dt}x(t)\stackrel{F}{\longleftrightarrow}j\omega X(j\omega)$
	- $\int_{-\infty}^{t} x(\tau)d\tau\stackrel{F}{\longleftrightarrow}  \frac{1}{j\omega}X(j\omega)+\pi X(0)\delta(\omega)$
Example
- If $x(t) = u(t)$ then $X(j\omega)?$
- let, $g(t) = \delta(t)$ then, $G(j\omega)=1$ and $x(t) = \int_{-\infty}^{t}g(\tau)d\tau$
- so, $X(j\omega)=\frac{1}{j\omega}G(j\omega)+\pi G(0)\delta(\omega) = \frac{1}{j\omega}+\pi \delta(\omega)$
