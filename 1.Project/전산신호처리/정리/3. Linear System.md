
First Order Step Responses
- Step signal을 주었을 때 system의 response

System Linearity
- 중첩 원리(superposition)를 만족하는 system이다.
- system을 $T\{\cdot\}$라고 할 때,
  $$
  T\{a x_1(t)+b x_2(t)\}
  =aT\{x_1(t)\}+bT\{x_2(t)\}
  $$
  가 임의의 input $x_1(t),x_2(t)$와 상수 $a,b$에 대해 성립해야 한다.
- 중첩 원리는 가산성(additivity)과 동차성(homogeneity)을 포함한다.
- 예: $y(t)=2x(t)$는 linear이지만, $y(t)=x^2(t)$와 $y(t)=x(t)+1$은 non-linear이다.

Linearization
- 작은변화인 $x^*, y^*$을 주어서 linear로 만드는 것
- $$\epsilon_{x}(t) = x(t)-x^*,\ \epsilon_{y}(t)=y(t)-y^* ,\ \\ \epsilon_{y}(t)=a\epsilon_{x}(t)$$

Time Invariant
- 만약 어떤 시스템에 $x_{1}$을 넣어서 $y_{1}$를 얻었을 때
- $x_{2}(t)=x_{1}(t-t_{0})$를 넣어서 얻은 $y_{2}(t)=y_{1}(t-t_{0})$인 경우
- Linear, Time Invariant systems = LTI

System with and without Memory
- with memory: 이전 입력이 출력에 반영되는 system
- without memory: 이전 입력이 출력에 반영되지 않는 system

System Causality
- 현재 시각의 output이 현재 및 과거의 input에만 의존하는 system이다.
- 즉, 시각 $t_0$에서의 $y(t_0)$는 $x(t)$의 $t \leq t_0$인 값들로만 결정되어야 한다.
- 예: $y(t)=x(t)+x(t-1)$은 causal이다.
- 반면 $y(t)=x(t+1)$은 미래의 input을 사용하므로 non-causal이다.

System Stability
- input이 bounded면 output도 bounded인 system
