- 우리가 알고 싶은 것: libc의 base주소
- 우리가 아는 것: puts@got의 주소 
- rdi -> 함수의 첫번째 인자 -> pop rdi로 rdi의 값을 넣으면 그 값을 출력할 수 있다

- rdi에 puts@got의 주소를 넣어서 해당 주소에 있는 값 = puts@libc 을 출력하겠다는 거구만

- buffer -> saved rbp -> gadget(pop rdi; ret) -> puts@got -> puts@plt
- 버퍼는 지나가고, pop rsp하면서 스택포인터 나오고, return되면서 gadget으로 가서 rdi에 puts@got를 넣고, puts@plt로 가서 puts@libc를 출력하겠다

- 출력한 것을 p.recvline(), p.recvn(6)으로 받아오고, \x00 두 개를 붙여서 크기를 맞춰서 u64로 언패킹 -> puts_libc에 puts@libc의 주소를 정확히 알 수 있다. 


- 이제 해야하는 것은 puts@got에 puts@libc가 아니라 system@libc로 overwriting하고 puts@got + 8에 "/bin/sh" 를 넣어서 이걸 rdi에 넣고, 인자로 전달해서 최종적으로 system("/bin/sh")을 실행시키겠다!!
- 여기서 질문 -> 어떻게 overwriting시키지?

- 다시 pip rdi; ret으로 rdi에 puts@got 주소를 넣어주고 ret로 gets함수 실행 -> 아까 얻어온 libc_base주소+system_offset하고, "/bin/sh"까지 입력해서 sendline으로 입력 -> 이렇게 overwriting하는구나 return oriented programming으로 gets를 다시 불러서~

- 마지막으로 pip rdi; ret을 하고 "/bin/sh"가 있는 puts@got+8 위치를 rdi 인자로 주고 실행 주소는 puts@plt를 넣어서 puts@got주소에 있는 system을 실행시킨다!

- 그러니까 전체적으로 처음 sendline에 넣는 payload는 stack조종용, 다음에 넣는 payload2는 got overwrite용
