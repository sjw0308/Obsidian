
- hexdump
	- 파일의 내용을 16진수 형식으로 출력하는 도구
	- 바이너리 파일이나 텍스트 파일의 내부 데이터를 분석하고 확인
	- 옵션
		- -C
			16진수와 ASCII를 함께 출력
		- -b
			바이트를 8진수로 출력
		- -c 
			바이트 문자로 출력: 제어문자는 이스케이프 시퀀스로 표시

- file
	파일의 유형과 기타 정보를 출력

- xxd
	파일의 내용을 16진수 형식으로 출력
	- vim에서 hex 값을 편집하는데 사용
	- 옵션
		-  -r 
			바이너리 파일에 기록 저장 가능

- objdump
	실행 파일이나 오브젝트 파일의 기계어 코드를 어셈블리어로 변환하여 출력해주는 도구
	- 실행 파일이나 오브젝트 파일의 내부 구조를 분석하기 위해서 사용
	- 옵션
		- -D
			모든 섹션을 디스어셈블 하여 출력
		- -x
			모든 헤더 정보를 출력
		- -M
			디스어셈블 하여 출력할 문법을 선택 (ex. intel, att)

- strace
	프로세스가 수행하는 시스템 호출과 시그널을 추적하는 도구
	- 운영체제와 어떻게 상호작용하는지 분석하기 위해 사용
	- 옵션
		- -f
			자식 프로세스까지 추적 수행
		- -e 
			추적할 시스템 호출이나 이벤트 지정
		- -p 
			실행 중인 프로세스의 PID를 지정하여 추적

- ltrace
	프로세스가 호출하는 라이브러리 함수를 추적하는 도구
	- 외부 라이브러리와 어떻게 상호작용하는지 분석하기 위해서 사용
	- 옵션
		- -f
			자식 프로세스까지 추적을 수행
		- -e
			추적할 함수나 라이브러리 지정
		- -p
			실행 중인 프로세스의 PID를 지정하여 추적
