
 - 리플렉션은 객체의 형식정보를 들여다보는 기능
 - Object.GetType()메소드를 이용해서 Type 클래스의 object를 return받을 수 있음
	 - ![[screenwriter_temp_1783094163119.jpg]]

- 애트리뷰트는 코드에 대한 부가정보를 기록하고 읽을 수 있는 기능
- 주석과 다르게 컴퓨터(컴파일러 등)이 읽고 경고 등으로 보여줄 수 있음
- ``` [애트리뷰트 이름(애트리부트 매개변수)] ``` 을 설명하려는 코드 위에 적으면 됨
	- ex. Obsolete이후 string을 넣으면 해당 코드를 실행할 때 컴파일러 경고로 보여줌
- 호출자 정보 애트리뷰트
	- ![[screenwriter_temp_1783094866236.jpg]]
	- 이것들을 애트리뷰트에 넣고(뒤에 써진 Attribute빼고) 선택적 인수 등에 사용하면 해당 애트리부트가 불렸을 때의 정보를 보내준다. 
- 사용자 정의 Attribute
	- System.Attribute 를 상속받는 클래스 만들고 안에 이름 넣으면 됨
