- value는 해당 프로퍼티가 lvalue로 쓰였을 때 rvalue값임

- 자동 구현 프로퍼티
	- 위 구조(get에 return 필드이름, set에 필드이름 = value 형태)인 경우 필드를 선언할 때 프로퍼티를 자동 구현으로 만들 수 있는데
	- ``` 접근_한정자 데이터_형식 필드_이름{get; set;} = default_value ```
	- 위 형태로 작성하면 get, set이 자동으로 구현되고, 디폴트 값까지 편하게 넣을 수 있다. 
	- 초기화 전용 자동 구현 프로퍼티
		- 위 형식에서 set대신 init을 넣으면 된다
		- 객체를 초기화 할 때 만 값을 넣을 수 있고 이후에는 readonly처럼 행동하게 된다.

- 프로퍼티와 생성자
	- 인스턴스 생성시 프로퍼티들을 이용해서 각 필드들을 초기화 할 수 있음
	- ![[Pasted image 20260518001201.png]]

- required 키워드
	- 프로퍼티 앞에 required가 붙으면 객체 생성 시에 함께 초기화 하도록 강제함

- 인터페이스와 프로퍼티
	- 인터페이스도 프로퍼티를 가질 수 있고, 형식은 자동 구현 프로퍼티와 같은 모습임
	- 이를 상속 받은 클래스들은 해당 프로퍼티를 구현해야 함, 이때 자동구현 가능
- 추상 클래스와 프로퍼티
	- 인터페이스와 다르게 구현을 가진 프로퍼티와 없는 프로퍼티 두 가지를 모두 가질 수 있고, 구현이 없는 프로퍼티는 상속 받은 클래스에서 구현해야함

- 무명형식
		- ```var var_name = new{Prop1=Value1, Prop2=Value2, ...}``` 로 무명형식을 만들 수 있음
		- ``` var_name.Prop1``` 등으로 접근 가능
