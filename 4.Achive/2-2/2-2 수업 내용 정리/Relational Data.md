Data is represented as a **Table** (or also called relation)
- A [[Database]] is represented as a set of tables
- Every row in a table has the same columns
- Relationships between tables are implicit (that means no pointers)
- Rows are records, tuples, instance, object, etc
- Columns are attributes, field, feature, dimension, etc

Attribute types are 
- Nominal (or categorical): Type of car, Color name, etc
- Binary: Gender, etc
- Odinal: Grade, etc
- Numerical: Height, temperature, etc
