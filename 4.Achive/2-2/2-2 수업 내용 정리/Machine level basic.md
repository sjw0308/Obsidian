- ISA(instruction set architecture, aka. architecture): processor design의 한 부분. Machine code와 assembly를 정확하게 쓰기 위해 필요한 것들을 정의해 둔 set. whats in ISA: instruction set specification, registers 등. ISA는 Intel, ARM, RISC-V 등이 있다. 
- Microarchitecture: implementation of the architecture. e.g. cache size and core frequency.
