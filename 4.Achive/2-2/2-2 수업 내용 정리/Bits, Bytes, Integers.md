- Each bit is 0 or 1
- Byte = 8bits(in hexadecimal, 0x00 ~ 0xFF)
- n-bit machine이면 해당 컴퓨터에서 pointer에 n bit이 할당되어있다는 의미이다.
- For x86-64(64bit) machine

|  C data type  | size (byte) | size (bit) |
|:-------------:|:-----------:|:----------:|
|     char      |      1      |     8      |
|     short     |      2      |     16     |
|      int      |      4      |     32     |
|     long      |      8      |     64     |
|     float     |      4      |     32     |
|    double     |      8      |     64     |
|  long double  |    10/16    |   80/128   |
