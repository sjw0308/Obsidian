- grammar G = (V, T, S, P)
	- V is a finite set of objects called **variables**
	- T is a finite set of objects called **terminal** symbols (like alphabet)
	- $S\in V$ is a special symbol called the **start variable** (like start state)
	- P is a finite set of **production rules** (like transition function)
	- Assume that V and T are non-empty and disjoint
	- Grammar로 만들어지는 string은 언제나 terminal로만 이루어져 있어야 한다. variable이 남아있다면 production rule을 더 거쳐서 variable을 제거해야 한다.
- 지금까지 Finite automata가 Recognizer의 역할이었다면 Grammar는 Generator의 역할을 수행한다. 

- Linear Grammar
	- production rule을 통해서 모든 variable이 (최대 하나의 variable을 포함한 body)로 변환되는 Grammar
- Regular Grammar
	- right-linear or left-linear grammar
	- right-linear grammar란 production rule이 variable을 변환할 때 나타나는 variable이 없거나 다른 terminal들보다 오른쪽에 있는 linear grammar를 의미한다. 
	- Regular Grammar $\equiv$ Right-linear Grammar $\equiv$ Left-linear Grammar

- Regular Grammar and Regular Language
	- A language is regular if and only is ti can be generated by a regular grammar
	- Proof 1(RL $\rightarrow$ RG)
		- L이 RL일 때 DFA M=(Q, $\Sigma,\ \delta,\ \ q_0$, F), L = L(M)이라고 하자
		- 우리는 RG G=(V, T, S, P)를 다음과 같이 설계하자
			- V = Q
			- T = $\Sigma$
			- S = $q_0$
			- P = $A\rightarrow wB$ for all $(A, w, B)\in \{(A', w', B')|\delta(A', w')=B'\}$ || P = $A\rightarrow\epsilon$ for all $A\in F$ 
	- Proof 2(RG $\rightarrow$ RL)
		- RG G=(V, T, S, P)가 L을 generate한다고 하자
		- NFA M = ($Q,\ \Sigma,\ \delta,\ \ q_0,\ \ F$)를 다음과 같이 설계한다. 
			- F = {f}, f is a new state for final state
			- Q = V $\cup$ F
			- $\Sigma$ = T
			- $q_0$ = S
			- $\delta$ = $\delta(A, w) = B$ for all $A \rightarrow wB \in P$ || $\delta$ = $\delta(A, w) = f$ for all $A\rightarrow w \in P$
