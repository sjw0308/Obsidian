data의 type은 아래와 같이 여러가지가 존재한다. 
1.  Table: Consist of records, attributes, etc. Relational database, transaction data
2.  Vector, Matrix, Tensor: Multi-dimension structure representing numerical data. Matrix는 table과 달리 모든 row, column의 data type이 동일 해야 한다.
3. Graph, Network: consists of nodes(vertex) and edges
4. Sequence or ordered data: ex. Language data
5. Time-series: ex. data from sensor
6. Image and multimedia
7. Spatial data: ex. Map
